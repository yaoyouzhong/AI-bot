# ESP8266 固件更新日志

ESP8266 与电脑桥接、TAB5 分别编号。

## 0.5.6 - 2026-10-26

本地候选，尚未公开发布。

- Codex 重置卡缩至 14 像素时，按源像素覆盖率保留细笔画，修复数字缩放后缺笔画。
- 数量与补零的 MM/DD 日期分列对齐；常规方框缩为 73 像素宽、18 像素行距，动画避让同步调整。临时字形缓冲区分配失败时使用内置小字体。
- 保留股票代码 Font2（16 像素）、协议、文件系统、配对及轮播设置，TAB5 不改动。

## 0.5.5 - 2026-10-26

本地候选，尚未公开发布。

- 使用现有字形缩放器，将 Codex 重置卡文字由 16 像素略缩为 14 像素，保留用户已确认的方框和留白；临时小字缓冲区分配失败时保留原本可读字号。
- 协议、文件系统、配对、USB／Wi-Fi 及展示设置保持不变，TAB5 不改动。

## 0.5.4 - 2026-10-26

本地候选，尚未公开发布。

- Codex 重置卡根据实际字体测量数量与日期的宽度，增加左右及上下留白；套餐标签为重置卡预留空间。
- 动画避让区域与方框共用尺寸，避免桌宠后续帧覆盖重置卡。保持协议 version=1、460800 波特率、配对、文件系统和轮播设置。
- PlatformIO 编译及 1,350 组实际字体尺寸边界检查通过；真机部署与视觉验收单独记录，未创建标签或公开发布。

## 0.5.3 - 2026-10-12

- USB hello／pong、USB 设备信息及已认证 Wi-Fi 设备信息上报由出厂 station MAC 生成的固定 `device_id`。不依赖 Wi-Fi 连接，不随 USB 插口、COM 号或重启改变。
- 配套 Windows 桥接从已确认连接登记固定 ID；换插口后先验证同一 ID，再自动更新 USB 绑定。保留协议 version=1 和旧版本兼容。
- 已完成本地安装、完整 Flash 备份及写入校验；真实 COM8 → COM7 换口后固定 ID 不变，自动恢复 USB 同步。另通过未配置 LAN 的实际串口恢复测试；验收期间未关闭小屏 Wi-Fi。未创建公开发布。

## 0.5.2 - 2026-10-09

本次同期发布；构建与分发材料校验通过，尚未刷入设备或完成实机验收。

- 电脑状态页的数字与曲线统一为最近四个 250 毫秒采样的 1 秒均值；整批消费新采样后同时绘制，避免数字领先曲线。
- 桥接采样会话改变时清除旧曲线；启动只平均已测得的采样，保留原字体、颜色及数字绘制失败降级。
- 保持协议 version=1、460800 波特率、配对和 USB／Wi-Fi 回退。

## 0.5.1 - 2026-10-08

- 从 firmware/VERSION 嵌入固件组件版本，通过 USB 心跳、设备信息及已认证 Wi-Fi 请求上报，使桥接能够判断可用升级。
- 旧版未上报版本的小屏先安装桥接 0.6.2，再使用“手动准备小屏升级”；通过 USB 完整备份、写入和校验。
- 协议版本仍为 1，保留现有页面、配对和 USB/Wi-Fi 回退行为。修复代码已用本地候选在真实 ESP8266 验证；0.5.1 正式包的完整安装验收独立记录，不把候选验收冒充新包验收。

## 0.5.0 - 2026-10-03

- 随历史 AI-bot v0.5.0 分发的固件基线。
- 后续以 `firmware/VERSION` 与 `esp8266-vX.Y.Z` 标签维护，桥接或 TAB5 更新不要求重新发布未改动的 ESP8266 固件。

已发布的 v0.5.0 固件不变；此基线之后的源码修改需要独立验证并补入对应版本条目。
