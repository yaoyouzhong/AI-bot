# 视觉对齐基线

2026-09-08 用户明确要求：保留旧版绝大部分展现形式，只有展示新旧对照并经用户认可更好的方案才替换。独立重实现不等于获准整体重设计。

## 默认保留

- 旧版各页面的信息结构、主次关系、字号层级、颜色含义、位置和用户习惯。
- Claude、Codex 单独页面，以及 Claude + Codex 双额度页；不能用目前仅显示活动状态的新版 `dual` 页冒充等价。
- 天气时钟、股票行情、国产模型、系统监控、音乐播放的主要布局和信息密度。
- 智能跟随及原有轮播语义；不能把新版固定轮播机制直接视作完成对齐。
- 桌宠与额度共同展示、屏保进入和唤醒的既有体验。

## 实施边界

- 先从旧版现有运行画面/可核验截图逐页建立基线，再独立实现；不以新仓库的当前截图作为默认设计。
- 显示样式调整必须同时核对固件与 Windows 镜像；平台未验证项单列。
- 新旧对比使用同一组数据。改进需指出具体收益，例如信息不被遮挡、数字更易辨认；不能仅声称“更现代”。
- 旧源码、图标和精灵图仍需遵守仓库来源规则。可保留展现结构，不因此直接复制来源不明的素材或第三方源码。

当前新仓库的界面**尚未达到此要求**。通信修复和链路测试通过也不代表视觉迁移完成；需要单独逐页对齐与实体屏确认。

## 已实施的屏保对齐

按用户明确指出的“小字时钟”问题，固件和 Windows 镜像改为：204×76 的四位七段数字，每位 42×76；青色数字、黄色冒号、黑底、灰白日期、黄色星期；日期位于数字下方 86 像素处，每 5 秒缓慢移动，底部保留离线状态区。布局来自旧版可观察规格，数字段与星期笔画为独立实现，不迁入旧位图。镜像检查移动边界不越屏；2026-09-08 用户针对实体屏确认“符合的”，屏保视觉验收通过。
