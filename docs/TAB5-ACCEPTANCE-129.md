# TAB5 0.2.129-ui 倒置横屏

用户确认 `.128` 竖屏朝向正确、速度可以后，指出横屏翻转 180° 仍保持原朝向。本版增加倒置横屏方向，正常横屏排版保持不变。

- 负 X 重力方向为正常横屏，正 X 为倒置横屏；正负 Y 为两种已确认的竖屏。
- 倒置横屏直接旋转原缓存图片与日期，复用同一分页，不下载额外图片。
- 保留 350 ms 稳定窗口、50 ms 界面方向检查、同分页另一方向预取和双帧缓存上限。

本地构建、四方向回归及实机验收进行中。证据：`artifacts/development/tab5-portrait-129/`。

## 实机反馈

已安装。用户反馈四方向仍不对，正常横屏反向且竖屏未触发，验收失败。当前传感器可正常采样，但部分读数接近平放，方向保持逻辑可能影响判断；等待固定正常横屏姿态校准，不能将本地回归通过等同实机通过。

## 后续未刷入修订

日志确认 .129 的 35°–38° 倾角接近原 Z 比例门限，造成新方向无法稳定触发。源码已改为面内重力投影判断，保留 4000 LSB 接近平放门限及主轴优势判断；15.6°、20° 支架角、四方向、防抖与故障恢复本地测试通过。此源码修订尚未生成或刷入新候选；正常横屏的原始轴基准仍需用户固定姿态确认，不能推断已经校准。当前用户验收状态仍为失败。

用户固定正常横屏后确认原始 X 为 +16186～+16211 LSB。`.129` 对正常/倒置横屏的 X 轴符号确实反了，后续按实测基准在 [.130](TAB5-ACCEPTANCE-130.md) 修正，保持已确认的 Y 轴竖屏映射。
