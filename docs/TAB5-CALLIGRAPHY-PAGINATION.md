# 书法分页与屏保适用性 / Calligraphy pagination

2026-10-06，根据当前catalog.json与provenance.json逐件统计。

**411件中188件有多个展示页，占45.7%；223件为单页。** 这里统计的是设备展示帧，不是原册页物理页数。131件使用多张原图，其中7件通过完整对联并排排版成为单页；另有64件使用一张原图生成全幅／局部。

Of 411 works, 188 have multiple display frames (45.7%) and 223 have one. There are 131 multi-source works, including seven complete pairs laid out on one frame, and 64 single-source works with overview/detail frames. Display-frame counts are not physical leaf counts.

**分页过多不适合日常短时间待机，但适合完整收藏和长时欣赏。** 超过8页的41件仍完整保留。优先选3页以内有301件；若允许最多8页则有370件，数量足够全年不重复。若日后把默认池严格限定为3页以内，仍需再补65件。每日目录现按展示页数升序排列，同页数保留原顺序，名画顺序不变；不设页数硬上限，不截断或删除长卷。日期仍按既有固定基准索引目录，因此更新后的日期与作品对应会随重排变化。

Many frames are less suitable for brief idle sessions. All 41 works exceeding eight frames remain intact. A maximum-three-frame pool has 301 works (65 short of a full leap year); a maximum-eight-frame pool has 370. The daily catalog now uses stable ascending frame counts, retaining every complete work and the painting order. No frame-count cutoff is applied. Existing date indexing is retained, so reordering changes the date-to-work mapping once the new catalog is deployed.

30秒来自现有固件的最低换页间隔；估算不含传输、重试与唤醒中断。小楷密度、拓本清晰度、装裱留白也影响适用性，最终仍需TAB5观看距离和亮度下验收。[新增短幅和本地候选](TAB5-CALLIGRAPHY-CANDIDATES.md)。
