## 国产额度确认的未完成项

`LegacyDisplayCache.ParseDomestic` 将旧 `PlanPct` 作为 `WeeklyPct` 的回退，而
`DomesticProviderQuotaSnapshot` 没有独立套餐总额度字段。当前渲染器据此标为
WEEKLY，无法完整恢复旧版 PLAN / REMAINING / RESET 的含义。这不是字号问题。
下一步需联动数据源、缓存、Windows/固件/macOS 状态模型与协议，并保留缺失字段兼容。
另外需恢复顶部状态点/会员徽标、底部 (20,177,200,38) 面板和 DeepSeek
AVAILABLE BALANCE / USED 币种布局；本轮没有把国产额度页标记为修复完成。

### 后续：天气的桌面镜像与设备规格分开

现场核对旧 MirrorForm.DrawWeatherScene 与固件 drawWeatherScreen 后确认：旧桌面
镜像用Consolas 48粗体HH/mm、25常规ss、24常规TEMP/HUMID，没有设备的进度条和
右下角动画。旧设备则有内置Font7时分、手绘秒钟和几何天气动画。不能混为同一基准。

- Windows新增WeatherMirrorRenderer，恢复上述字体、坐标、黄色分钟、城市字号测量、
  供应商天气文字配色及空气徽标。原近似设备预览仅保留为独立DrawDevicePreview，
  不再作为托盘镜像或验收依据。
- 固件保持天气动画/桌宠，秒钟恢复16×30、3px圆角笔画；时分不再随每秒重复绘制，
  湿度图标中心与标签纵坐标恢复旧值。本轮未更改天气数据协议/缓存格式。
- 读取正在运行的旧桥接/weather生成新镜像预览，没有切换App或修改设备。
- 自测覆盖城市时区跨日、黄色分钟、设备动画选项不影响桌面镜像，多字城市/空气质量
  与缺失数据预览。Windows/固件构建及本地检查不是光学实机验收；日期资源跨日更新、
  刷新抖动和全部动画仍须真机核对。
