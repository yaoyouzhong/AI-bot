# 全功能对齐审计：本地结果与未闭环项

本记录是一次扩大的本地对齐批次，不代表全功能迁移完成。旧版继续运行，本轮未刷机、未切换常驻桥接、未推送或发布。

## 后续批次：切换时序和真实数据生命周期

已修正 AUTO 相位：Windows/Mac 用单调时间记录最后实际切换，重复状态不重置停留时间；通过 `followApp` 把选择传给固件，镜像不再另算相位。隐藏页面不推进选择，回到自动页时按经过的停留时间最多切换一次。新增测试覆盖唯一工作、同时工作、都空闲、固定页、等待输入、重复调用和 USB 字段保留。旧协议没有 followApp 的兼容路径仍用旧取模算法，不把兼容路径称为相位一致。

音乐修正：缺封面不再生成黑图；播放器结束时不显示旧文本/封面文件；Windows 连续三次空采样才清空，后到的封面可在同一曲目继续刷新。Mac 同步 hasArtwork 状态和资源清理，补充 XCTest；修复上一批 Mac 测试写入 let 字段的问题。Windows 数据生命周期测试通过；Mac 仍未编译，真实播放器和设备仍需验收。

下文“当前相位基于桥接轮播锚点”和“状态转换相位待修正”是上一批历史，已由本节的新桥接路径替代；真实设备时延与切换仍未验收。

本批次验证：Windows Release 零警告/错误，14 组自测与 25 个旧版镜像对照再次全部通过；状态 JSON 已包含 followApp。固件 RAM 42,164 / 81,920、Flash 511,567 / 1,044,464，构建成功，既有警告仍在。只读媒体检查返回 session=none、playing=False，不能据此认定真实音乐验收完成。旧版 HTTP 状态返回 200。没有刷写或改变旧版运行程序。

## 新旧直接比较

`--audit-legacy-scenes <旧版 AIClockBridge.dll> <本地输出目录>` 只加载用户本机旧版的 MirrorControl，不运行旧版入口、网络服务或串口。构造相同数据后分别绘制 240×240 图像，比较全部 57,600 像素；不屏蔽图标、宠物或边缘差异。旧版程序集 MVID 为 `24260cda-2d00-45e6-866d-9522e8ae1e5d`。

当前 25 个案例全部零差异：

- 股票空数据、四行（中英名称、长名称、省略、涨跌平）。
- 音乐空数据、无封面播放、暂停。
- 系统监控 224 点历史曲线及 CPU/内存。
- 双额度 PRO、PLUS、MAX 5X、TEAM。
- 阿里云、Kimi、MiniMax、DeepSeek。
- 屏保当前时刻；天气长/短城市名。
- Claude/Codex 单额度及待确认红框。
- Codex 仅周额度、100% 额度、0/1/2/5 张重置券（含重复到期日）。

屏保/天气的旧版取系统时间，跨秒/跨 5 秒边界可能产生真实时序差异，运行失败必须检查原因，不得直接屏蔽失败。动画固定使用本地当前选择的首帧，因此不能证明工作动画的运行时切换。

另行实测：默认 Claude 111×120、Codex 120×120，各 6 帧的每个 RGB565 像素和延时与旧版头文件一致。当前 6 只自选股名称的 62,400 像素与运行中旧版 `/stock/names.raw` 一致（先归一化字节序）。

对比截图位于本地 `artifacts/legacy-scenes/`，不纳入公开仓库。桌面图标从用户本机旧版导入 `%LOCALAPPDATA%/AI-bot/page-logos/*-mirror.png`；设备 RGB565 资源保持独立。公开包不嵌入旧图标。

## 本轮修正

- 股票页脚字体及无数据提示；音乐页抗锯齿。
- 国产镜像多出的灰色轨道、标题/说明字重、重置文字基线、余额单位的小数坐标；移除旧版没有的 LOCAL TOKENS 底栏，数据仍保留在状态中。
- 屏保镜像恢复矩形数码段、19px 日期、完整黄色星期、旧版配色及移动范围。桌面没有 PC OFF 底栏，固件保留独立底栏安全区域。
- 单额度图标避免以设备 16 位色深替代桌面原图；红框厚度及位置；多张重置券与宠物重叠处恢复原透明混色。
- 股票恢复腾讯失败/空结果后尝试新浪，两源均失败保留最近成功缓存，恢复后解除过期标记；修复平盘符号及非有限数字校验。
- AUTO 补齐两应用均工作时 2 秒轮换、均非工作时 6 秒轮换，以及国产活动优先级。Windows/固件/Mac 共用相同规则；当前相位基于桥接轮播锚点，不是旧设备每次唯一工作状态切换后的计时器，状态转换瞬间的精确相位仍需进一步闭环。
- 固件额度轨道恢复旧设备 `0x2104`，去除新增国产页底栏。没有因桌面无轨道而误删设备原有轨道。
