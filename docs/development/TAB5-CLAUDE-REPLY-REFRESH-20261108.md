# TAB5 Claude 最新回复刷新优化（2026-11-08）

## 设计

用户在 TAB5 最新回复页等待 Claude 输出时，希望终端已有回复能够更快显示。保持 1280×720 横屏、现有文字、字体、颜色、按钮尺寸、阅读位置和历史页交互；不新增界面元素。仅当 Claude 最新回复页可见、跟随最新且桥接明确报告本轮 `inProgress` 时，将一次成功读取完成后的下一次读取间隔从 3000 ms 缩短至 750 ms。完成、未知、历史页、隐藏页面、Codex、断线和错误保留原节奏；正在发送、同步或读取时继续沿用现有互斥保护。

Mac Claude 回复读取的后台缓存刷新阈值从 1000 ms 缩短为 500 ms，使 750 ms 轮询可触发后台更新；保留同设备/会话/页身份绑定、单个后台任务、有界过期以及失败时保留最后成功内容。Codex 阈值保持 1000 ms。请求仍从既有链路发起，不增加后台发送，不改变协议。

目标是缩短运行中回复变化的轮询等待，并控制屏幕不可见时的资源消耗。设备与桥接定时器、传输和模型生成时间仍影响实际速度；实际改善必须用对应候选及设备测试测量。
