# Mac 首次授权设计与验收

适用于首次打开 AI-bot Bridge，也用于当前应用因升级签名变化而失去系统授权的恢复。天气定位与 Codex 直达用的是两项不同的 macOS 权限。功能采用已有默认值；权限通过后无需再打开应用内开关。手动天气地点、原有功能关闭设置和系统拒绝均保留。

原生窗口沿用设备中心的 680 点宽、24 点边距、16 点组距（组内 6–8 点）、23 点标题、15 点分组标题、12 点说明及系统浅色／深色样式。天气定位、Codex 直达分两组，每组显示用途、权限状态和可键盘访问的系统授权按钮（大号原生控件）；授权动作在各组内，底部次要操作允许稍后完成。显示为“已授权”后该组隐藏授权按钮；未开启相应功能时仅显示状态。首次需要授权时显示一次，此后可从菜单栏右键菜单或“窗口”菜单打开“系统授权…”。无授权不阻止 USB 配对、查看会话或手动天气。麦克风、音乐或 Terminal 的自动化等仍按实际使用请求，钥匙串由系统处理。

发版验收须使用同一候选的实际安装包：独立 macOS 用户验证首次启动、允许或跳过、授权后天气刷新与 TAB5 定位／上一个／下一个、退出重启后无额外应用开关；再用旧公开包验证覆盖安装、实际授权状态和恢复入口。显示为已勾选但权限未生效时，移除旧辅助功能条目并重新加入“应用程序”里的 AIBotBridge.app；不要重置整套系统隐私权限。

本机旧条目曾显示勾选，而运行中的桥接报告未授权，TAB5 的直达请求返回 409。关闭再打开旧开关及重启桥接均未解决；移除旧条目并重新添加应用后，桥接读到真实授权，用户验证了定位、下一个、上一个均正常，没有向会话发送消息。已下载并核对公开 v0.6.19 Mac 附件的 SHA-256；该包的应用签名缺少定位 entitlement，新候选已补齐。

候选已用原生 AppKit 离屏渲染检查授权前后、浅色与深色、默认和最小尺寸。首版最小窗口按钮靠近底部，收紧组内间距后复查正常。隔离回归验证首次显示、拒绝时进入系统设置、已授权不重复请求和关闭后不反复弹出；这不能替代独立 macOS 用户的真实系统授权。Swift 通过 520 项（4 跳过，0 失败）。
