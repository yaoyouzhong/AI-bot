# Windows 官方语音识别接入（2026-11-02）

## 实现前设计

- 本次接入微软 SAPI／System.Speech，使用已安装的简体中文识别器；不等同于实验性的 Windows AI Speech Recognition，也不调用 Win+H 在线键入。现场 Windows 11 build 26340 已注册 Microsoft Speech Recognizer 8.0（zh-CN）。
- 沿用已对齐 Mac 的语音设置页面、560×480 逻辑尺寸、最小 520×420、24 外边距、90 标签宽、系统字体和既有颜色。识别方式改为可选“豆包输入法／Windows 本地识别”，默认保留已有豆包配置。收音状态随识别方式更新；未安装微软中文识别器时明确提示并阻止保存，保留原设置。Windows 识别不要求 VB-CABLE，输入设备规则与现有麦克风选择一致。
- 保存、取消、刷新、并发设置校验继续包含识别方式和麦克风；加载期间及录音期间不得写入。旧配置缺少 Provider 字段时保持豆包；切换设置只影响下一次用户发起的录音。
- Windows 后端直接接收 TAB5 的 16 kHz／16-bit／单声道 PCM 或所选电脑麦克风，识别结果沿原语音协议回到设备预览，由用户手动发送。无需切换输入法、设置系统默认音源或聚焦桌面文本框。不改固件、Mac 或协议格式。
- 本地音频仅在内存中有界缓冲；取消／设备断开／窗口关闭／迟到结果按会话隔离。音频及识别文字不得写入日志或仓库。自动化使用内存合成语音，不打开真实麦克风、不发消息。
- 微信范围已确认是微信输入法。官网公开资料及当前运行窗口的只读检查尚未发现可验证的官方桌面语音 API／可确认的开始结束状态，不把私有进程注入或只发快捷键当作可靠接入，不增加虚假可用选项。
