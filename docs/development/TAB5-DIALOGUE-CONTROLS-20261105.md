# TAB5 对话页控件修正

用户报告相机与麦克风底色不一致，以及项目下拉框文字干涉箭头。以已验收 `.315` 源码为基线另存修正，不覆盖该 BIN 或其验收。

项目选择框保持 262×48、原位置与 24px 字体；左右各 12px，箭头预留 24px，与文字间隔 12px，文字区域为 202px。独立单行文字使用省略显示，不参与点击，完整项目名称保留在展开列表，继续由原 dropdown 处理选择、禁用和离页关闭。LVGL 原生 dropdown 将选中文本按完整宽度绘制，没有扣除箭头区域，这是长名称重叠的原因。

用户进一步指出图标缺乏设计、右侧摆放拥挤；最终方案将输入工具和提交操作分开。相机、麦克风移至输入区左下方，横坐标 0/76、纵坐标 332，按钮均为 56×56，净间距 20px；发送仍在右侧横坐标 598，留出 466px 分组间隔。录音时的来源切换按钮放在横坐标 152，取消保持右侧；不让文字提示挤进按钮区。

两个输入工具使用同一圆形底板和低对比 1px 边框 `#465C65`，线性图标为 2px 线宽、约 26px 视觉高度，按光学中心放置。沿用前景 `#EFF4F2`、普通底色 `#354247`、按下 `#465C65`、禁用 `#303A3E`；录音 `#365D48` 与停止图标保留。用户已确认色差发生在空闲状态；新普通态的几何和颜色保持一致。禁用态整体 50% 不透明度。专用麦克风图标不改变其他页面的共享语音控件。操作路径和协议不变。

完整状态约定：相机始终留在原位置，等待准备、录音、音源切换和识别时禁用，结束、错误或取消准备后恢复；延续已有禁止录音并发拍照的保护。麦克风/停止按钮不移动，DJI 录音时显示相邻的“改用 TAB5”，TAB5 录音时收起该按钮，取消保持右侧。提示仍在按钮行下方的同一反馈槽，沿用已有互斥清理，不改发送回执数据。外接键盘提示移至横坐标 336/纵坐标 348/宽 240，与切换及取消均有间隔。

原生渲染需检查中英文长项目名、下拉选择和收起、两客户端，以及普通/按下/录音状态。编译或预览不代表部署；实际新镜像需单独核验和真机验收。

当前两客户端的项目选择/离页关闭、普通/按下按钮一致性、绿色录音与停止图标、草稿恢复、客户端切换、相机就绪和四方向照片上传过渡原生回归通过。“改用 TAB5”事件仍提交原动作 3。真实 LVGL 渲染覆盖普通、按下、准备、DJI 录音、切换、TAB5 录音、识别、错误及外接键盘；控件边界检查覆盖工具分组、切换按钮、键盘提示、取消及下方提示，忙碌时相机保持可见且禁用，结束后恢复。
