# 菜单栏活动提示修订（2026-11-02）

## 设计

鼠标悬停菜单栏图标时沿用 macOS 系统 tooltip 的原有三行、字体、颜色及间距：第一行应用名，后两行分别是 Codex、Claude。状态为“工作中”“空闲”“近期有活动”“无近期活动”或“检测中”。已有可靠工作／空闲信号优先；不足以证明当前工作但文件最近有更新时使用“近期有活动”，不可把近期文件更新等同于模型仍在运行。没有近期活动不再称作“离线”；后台扫描尚未完成时用“检测中”。不新增按钮、点击区域或前台窗口，不影响设备协议和状态。

近期活动仅检查本机既有目录下会话文件的修改时间、文件类型和符号链接属性，不读取正文、路径或凭据，不持久化扫描结果；后台异步执行，失败保留未知。离屏检查系统字体下的文本宽度、对齐及多行可读性；Mac 实时状态和用户的实际悬停效果分别验收。

已用 AppKit 系统提示字体对“近期有活动／无近期活动”与“工作中／检测中”制作离屏文字预览并检查：三行对齐清晰、未截断。此预览模拟系统提示内容，系统实际悬停气泡仍须用户自行观察。扫描结果超过 30 秒后不再视为完成，避免扫描卡住时长期显示过时结论。

2026-11-02 全量 `swift test` 429 项和 Release 构建通过，签名桥接安装并从 `/Applications/AIBotBridge.app` 后台启动。用户确认悬停可见 Codex 近期有活动、Claude 无近期活动；两者表示文件近期活动情况，并不单独证明程序是否仍在运行。用户重新授权固定路径后确认 TAB5 会话直达成功，桥接诊断返回定位 200。
