## 背光排查与设计补充

用户进一步描述切页现象类似亮度或背光突变。静态代码核对发现确定的启动缺陷：原 `setup` 先以 PWM 应用保存的亮度，然后 `TFT_eSPI::init` 对同一 GPIO 调用 `digitalWrite`；ESP8266 Arduino 的 `digitalWrite` 会停止 PWM。候选将背光 GPIO 单独命名并由固件独占，保持 GPIO 5、低电平点亮、原 0–100 映射和用户保存亮度，让驱动初始化不再改写它。页面尺寸 240×240、字体、颜色、位置、轮播和操作均不变。`firmware/test/test_backlight_ownership.py` 检查构建宏、PWM 映射、显示驱动初始化调用及初始化顺序；ESP8266 最终构建通过。真实亮度和开关电平仍需在设备观察。

源码没有显示页切换时显式改写亮度，且设备当前固件版本、供电和实际 PWM 波形未观测到。该启动缺陷不证明切页亮度波动的唯一原因。切页清黑和 UI 绘制流程保持不变，不能声称切页问题已修复；候选尚无真实渲染预览或真机验收，因此尚未满足用户“准备好后再刷机”的条件。
