## 实现前设计

- 股票镜像沿用 240×240、四行、行距 54、代码区 `(14, 6+54n, 56, 16)`、名称区 `(70, 6+54n, 156, 20)`。直接使用固件已授权的 Roboto Mono 4-bit 覆盖字模，不安装系统字体或重新选字体；常见不超过七字符为 8×16 格，八字符采用固件既有 7 像素步进，更长按固件规则截断并显示末格省略点。颜色与覆盖混合逐像素对齐固件。
- 普通切页、供应商切换及股票内部五秒翻页，均由现有 `PageTransition` 完成 90 ms 降至用户亮度 70%、绘制后 110 ms 恢复；Windows 不发送模拟淡入淡出的亮度序列。
- 重连检查优先增加后台可读的 USB 传输元数据：连接次数、资源实际发送／ACK／重试／同内容跳过、状态帧和亮度请求。仅保留有界事件，不含资源正文、配对令牌、图片、城市、股票名称、账户数据或硬件序列号；诊断仅绑定 loopback，并拒绝带浏览器 Origin 的请求。
- 同一已确认 USB 连接中按实际资源内容去重，避免不同 revision 但字节相同的数据重发；失败不记作已发送。每次重新握手清空发送缓存，不跨设备或重启盲信旧 ACK。明确的用户亮度操作继续按既有协议发送，先用计数判断是否存在后台重复指令，不把无 ACK 的发送假定为设备已经应用。
- 固件现有 `ResourceDedup` 接收校验后比较安装文件；相同资源不替换正式文件、不增加绘制代数。但候选临时文件仍会接收写入，不能描述为零 Flash 写入。TFT_eSPI 已移除 `TFT_BL` 宏，GPIO 5 的 PWM 由固件独占。以上是源码事实，需与实际设备采样及用户重插观察分别记录。
