# Mac 原生终端 Claude 会话

用户在已有 Terminal 或 iTerm2 标签页运行桥接的 `--claude-terminal` 命令，直接使用原生 Claude Code 交互界面。需要接续历史时传入 `--resume <完整 UUID>`，在原会话退出后执行。桥接只向这个启动入口创建的本地 PTY 写入，标签页关闭即结束会话。普通入口打开的终端可查看历史。Mac「会话与权限…」的 Claude 会话区可以复制当前桥接的启动命令。此入口无需开启 macOS 自动化或辅助功能权限。

TAB5 沿用 1280×720 的「对话 → Claude」、会话来源「原生终端」、原会话标题、拍照和草稿列表。输入区、字号、颜色、间距与点击区保持一致。空闲时显示发送，运行中按当前轮次显示追加和停止。等待用户输入、有电脑草稿、目标失联或无法确定时暂停操作，原草稿和回复保留。Mac 功能页在 Claude 会话说明区添加启动提示及「复制终端启动命令」次要按钮，沿用次级标签样式、系统字号、标准按钮点击区和现有行距。协议使用现有会话能力字段。

启动器在当前标签页原样转发键盘输入和原生 CLI 画面，桥接通过同用户私有 Unix socket 联系它。派发须核对同一 UUID、进程和前台进程组、默认快捷键和空白输入区。图片沿用现有加密上传及本地引用回执。追加使用 Claude 的队列提交，停止只发送一次 Ctrl+C，并由原轮次的历史终态确认。

运行 `swift test --package-path mac-app` 后，在 macOS 上从仓库根目录运行 `python3 tools/probe_mac_claude_terminal.py`。回归在 Terminal 和 iTerm2 的环境标识下，用 Claude Code 2.1.318、测试 PTY 和本地模拟服务验证续接、保留电脑草稿、文字、三张图片、运行中追加和精确中断。没有前台窗口操作或实际模型调用。
