# Mac 对齐 TAB5 R12：草稿与升级状态

以 Windows `a13769074383aabb15c84597ee6de3b54c465072` 和 [R12 交接](MAC-TAB5-R12-HANDOFF-20261110.md)为基线。用户在设备切换会话或升级前可能同步已不在近期目录中的草稿；读取和保存保持设备与会话隔离，真实消息操作仍需当前目录及权限。未确认送达的未知会话不得用空草稿覆盖待核对原文；不自动重试发送。

Mac 固件设置界面沿用现有状态文本区域、字号、布局与按钮触控尺寸。设备拒绝升级后显示已有具体原因，并在同版本心跳重复到达时保留；主动更换/取消固件、重新请求或真正开始传输时进入对应的新状态。USB 最后一块传输结束后，只有绑定设备、主机、序号的认证心跳证明设备已重启且升级空闲时才提前释放占用，并显示等待精确镜像核验；没有可靠证据继续原有保护。设备的 R12 图标及设置页设计沿用 Windows 已验收的共同固件，不添加 Mac 专用图形。设备升级保持独立授权和精确镜像核验，不凭版本相同认定成功。

验证覆盖 Codex/Claude 缺失会话读写、跨设备隔离、未知送达空草稿保护及消息操作拒绝；固件状态机覆盖拒绝原因、重复心跳、清除、重新选择和启动。同版本 OTA 租约是否需要提前释放应基于 Mac 现有的绑定和实时证据检查，不通过反复刷机验证。实际设备状态、渲染和未测项另行登记。
