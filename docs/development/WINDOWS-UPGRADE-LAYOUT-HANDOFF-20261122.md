# Windows 升级耗时与设置窗口布局

Windows 0.6.27 升至 0.6.28 的本机日志显示，32 MB 安装包写入约 22 秒，安装器运行 10 秒，安装器请求重启到新版受保护托盘进程启动约 139 秒。此段包含复制文件、校验受保护目录、迁移防火墙规则和启动计划任务，旧日志无法逐项分摊时间。

Windows 修改覆盖软件固件页的安装前确认、安装包分段传输和已验证运行文件的复用。点击升级即下载。安装包校验成功后，用户选择「安装并重启」或「稍后」。稍后安装会复用已下载的安装包。仅对桌面安装包使用 8 MiB 分段。保留下载摘要、受保护目录和文件校验、任务及防火墙规则检查。部署时分段记录准备和校验耗时。

确认窗把当前版本和目标版本放在标题下，只用一行说明程序何时退出和重新打开。底部单独排列「稍后」和「安装并重启」，Esc 或关闭窗口均保留安装包。

从新版桥接内发起升级，已安装的桥接和便携程序都在用户确认后以 `/VERYSILENT` 启动安装器，完成后自动打开桥接。手动双击安装包仍使用安装向导。旧版桥接传给安装器的参数由旧版决定，首次升入此版本时仍可能显示安装进度。

电脑提醒的设置与历史记录分为两个页签。设置页按提醒内容、声音与勿扰分组，起止时间与勿扰开关同行，保存固定在底部。配置迁移首页并列对齐操作说明和文件按钮，选择备份后显示对比表与恢复操作。两种布局沿用 Windows 桥接字体与配色。

## 验证

- Windows Release 构建、状态快照、下载与取消、确认框稍后及开始、4 次分段请求下载 32 MB 安装包与文件摘要校验通过。
- 下载后点「稍后」，再点升级并确认，界面测试记录一次安装包下载。重新创建更新服务后可按发布摘要复用缓存，缓存损坏会重新下载。
- Windows 沙盒中从运行的公开 0.6.27 覆盖安装测试包，从启动安装器到新版受保护托盘就绪为 23.84 秒，其中安装器请求重启到托盘就绪约 5.5 秒。安装期间每 40 毫秒轮询一次，未发现可见安装向导。核对新版进程的 DLL 摘要、旧进程退出、用户设置和加密解锁记录。76 个运行文件中复用了 71 个。计时不含下载、用户确认及确认后启动安装器前的准备。
- 最终界面版在全新 Windows 沙盒中另测实际升级交接。测试程序从安装确认后的包校验、安装身份检查和受保护安装包暂存进入生产中转程序，运行公开 0.6.27 的托盘由安装器正常关闭，再核对新版托盘 DLL 和可用事件。总耗时 34.75 秒，未检测到可见安装向导，原有局域网许可、设置和加密解锁记录通过核对。该次计时不含下载和用户考虑时间。另在沙盒桌面实际显示确认窗并截屏，检查主次操作和文案。
- 两窗的默认与最小尺寸按 100%、150%、175%、200% 渲染。提醒设置开启勿扰时逐个核对可见控件边界及纵向滚动条。配置对比核对可见记录和恢复按钮的选择状态。
- Windows 沙盒在旧托盘退出后从启动器启动，校验受保护进程 DLL 并等待托盘退出事件就绪。公开 0.6.28 用时 9.6 秒，优化样本 8.9 秒。单次对照，未复现用户电脑的长延迟，完整公网升级耗时仍待新版实际升级验证。
- 本机综合开发界面测试在独立的 TAB5 显示设置最小窗口发现「下移」按钮截断。两个设置页另行通过定向渲染测试。

## Mac 对齐

受保护安装目录、计划任务、Inno 安装器和 WinForms 窗口都属于 Windows。Mac 接收端可在 MacUpdateWindow.swift 的桥接更新入口核对正式升级前的确认交互；本次未修改或实机验收 Mac。设备协议和固件无改动。
