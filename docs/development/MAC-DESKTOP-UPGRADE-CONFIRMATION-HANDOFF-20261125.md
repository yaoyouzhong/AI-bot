# Mac 桥接升级确认

## 对齐范围与界面设计

- Mac 接收 Windows [升级交互](WINDOWS-UPGRADE-LAYOUT-HANDOFF-20261122.md)：点击「一键升级」先下载、校验 ZIP 并检查应用的版本和签名。只有确认「安装并重启」才交给现有 Mac 安装链路；「稍后」或 Escape 保持当前桥接运行，并保留 ZIP。下次选择同一更新，重新校验并复用完整缓存，不自动安装。
- 沿用「软件固件」更新窗口的尺寸、布局与底部状态区。确认使用附着于该窗口的原生 AppKit 提示，尺寸由系统根据标题、两行说明和标准按钮决定。说明以「当前版本 → 目标版本」开头，再说明应用会退出并自动重新打开。按钮使用原生点击区域、系统字体、间距与浅／深色，主操作「安装并重启」，次操作「稍后」；等待确认时不允许重复发起更新。选稍后后回到更新页，可继续查看或操作其他更新。
- Windows 已有等价交互，无需改动。不照搬 Windows 静默安装器、分段传输或系统目录优化。TAB5、ESP8266、图库、设备协议和更新检查周期不变。
