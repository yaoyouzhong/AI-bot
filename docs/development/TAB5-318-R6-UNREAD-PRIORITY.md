# TAB5 318-R6：让当前项目的未读会话出现在视野内

在 TAB5「对话」页，用户可能正停在左侧会话列表底部。当前项目收到新回复时，按回复到达顺序将未读会话排到顶部，最新在先；其余会话沿用原目录顺序。首次打开已有未读的项目时也从顶部显示。只改变左侧列表顺序和视口，不切换厂商、项目或当前会话，不打开正文、不标记已读、不改草稿。

沿用 342 px 列表、80 px 行高、8 px 行距、既有字体和触控区域。背景 `#354247`，选中底色 `#465C65`，未读底色 `#41483E`，角标继续使用 `#F1BB57`。视觉层级由排序与原有「未读」角标表达，不加分组标题或动效。手指按住列表、正在拖动或仍在惯性滚动时，等操作结束才将新未读置顶并定位；同一条回复的重复状态帧不打断手动滚动。其他项目或厂商有新回复时仍用原有提醒，不替用户切换。

以已核验的 R5 源码为基线，保持 `0.2.318-ui` 协议版本，内部标识 R6。用 64 条模拟会话验证底部收到新回复、按住时延后定位、重复心跳、未读取消及其他项目隔离，核对实际 LVGL 渲染；设备验收单独记录。
