# 0.2.47：回复中的货币符号

用户真机照片显示余额和累计使用金额前有缺字方框。原 24 px 正文、30 px 标题字体使用 GB2312 字符集，包含全角人民币符号 U+FFE5（￥），没有半角 U+00A5（¥）。

两份生成脚本同步加入 ¥、€、£、—、•。仍使用相同 SHA-256 校验的 Noto Sans CJK SC Regular 源字体、lv_font_conv 1.5.3、2 bpp 和原许可证；不替换回复文本或货币值。重新生成字体使后续构建也保留这些字符。

原生 UI 检查两种字号的六个符号能返回实际有尺寸的字形，并渲染标题、正文中的 ¥75.37、¥24.62、￥75.37、€12.50、£8.00。没有用隐藏缺字框或替换为空白掩盖问题。构建和字体预览通过后提供本地候选，安装与真机同一条回复的显示待验收。
