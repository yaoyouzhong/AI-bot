# 0.2.40 连接恢复、电脑状态与滑动候选

> 历史阶段记录。当前实现、验收状态和升级通道边界以 [0.2.52 收尾清单](CLOSEOUT-052.md) 为准；下文的“待实现/待部署”仅描述当时状态。

## 本轮现场证据

- 用户确认轮播已通过；卡顿集中在四个主页面左右切换。
- 用户确认设备固定蓝牙。此模式不因插上 USB 而改走 USB，保留该设置。
- 0.2.39 已通过 USB 实时 ping 读回；此前桥接的 14:37:12 诊断缓存已过期，不用作版本或滑动证据。
- 用户提供的 .NET 堆栈定位到 `SerialStream.Dispose -> Tab5Service.CloseUsbPort -> RunUsbAsync -> StopAsync -> ExitThreadCore`。设备拔线后的 IOException 终止了 USB 工作线程，退出时再次传播。清理现只容错 IOException，其他异常仍传播；新句柄可以继续打开。
- 更新桥接后 USB 诊断恢复实时。固定蓝牙的旧固件整帧约 27 KB，现场曾测 9.9 秒；不能把 250 ms 采样等同于 BLE 已达到 4 Hz。

## 改动

- USB 图标改用 TinyUSB ready（已枚举且未挂起），适配电池供电下拔线后 mounted 状态残留。
- 空闲语音/RPC 邮箱轮询从每 30 ms 改为 250 ms，降低同一 GATT 会话的竞争；实际分片仍连续处理。
- `telemetryVersion:1` 表示支持电脑状态小包和完整状态压缩。旧固件保持原协议；Wi-Fi 使用已验证的固件版本证明进行兼容判断。
- 电脑状态复用原 AI-bot 的 250 ms 采样。USB 单独发送小包；电脑状态页 Wi-Fi 请求目标间隔 250 ms；BLE 按无线实际完成速度发送，不堆积过时采样。
- 完整状态压缩为 zlib + base64，仍由原有加密通道保护，解压严格限制在 32768 字节内，不允许嵌套压缩。OTA 提示从已验证的完整状态更新，覆盖三通道，小包不撤回 OTA。
- 小包仅替换电脑状态，必须匹配当前配对与完整状态的 session，独立防乱序；不会延长会话/任务心跳。较旧的整包不能覆盖更新的采样。
- 主页面拖动/吸附期间延后 JSON 深拷贝、任务控件更新和草稿同步；结束后应用最新数据。录音、相机和告警处理保留。
- 包含 0.2.39 之后的网络诊断页底部提示裁切修复。
- CPU/内存占用按整数百分比四舍五入，文本中心对齐仪表盘中心；网络速度精度保持原样。
- 设置保存成功提示 3 秒后隐藏，失败提示持续保留，下一次成功后恢复自动隐藏。
- 固件升级页没有新固件或已是最新版本时收起说明区，版本卡片从 332 px 缩至 90 px，升级按钮和状态提示同步上移；新固件可用时恢复完整说明区。
- 新增 RGB565 半字偏移拷贝候选，启动时用 PSRAM 实测两种对齐情况；只有快至少 10% 才启用，否则保留 memcpy。原旋转、DMA 所有权和 4 MiB 页面缓存上限不变。不是已确认的 FPS 提升。

## 本地验证

- Windows Release 构建、TAB5 全套、RPC、BLE voice、status-once。
- `--self-test-tab5-telemetry`：原格式回退、压缩逐字节还原、小包读取最新采样；合成任务目录，不向真实会话发送消息。
- `telemetry-receive-test` 编译实际接收函数：USB/Wi-Fi/BLE、完整包压缩解码、小包排序、跨 session 拒绝、不修改完整包心跳/OTA、大小边界。主机使用已安装 Git zlib；固件使用 ESP32-P4 ROM miniz，ROM 路径仍需真机验收。
- 原生 LVGL：原有全部回归，以及更新采样显示、滑动中不复制整包、松手应用最新数据、旧整包不使曲线倒退。
- ESP-IDF 5.4.2 构建；构建和模拟均不替代真机结果。
