# TAB5 布局优化

目标：1280×720 横屏桌面信息面板；远处辨认状态，近处触摸切换。资源继续本地缓存，布局完全在设备绘制。

## 2026-10-11：显示模式选择（本地开发）

“内容轮播”的显示方式合并为三个互斥选项：内容轮播、固定页面、自动切换。轮播显示间隔及勾选／排序列表，固定显示页面选择，自动仅说明音乐播放时显示音乐、其余显示总览。选项下方的总览模型选择独立保留。切换模式和固定页面时留在设置页，退出后显示目标页面。

沿用现有 `selected`／`cycle` 及 NVS 结构：轮播为 `-1/true`，固定为 `0..7/false`，自动为 `-1/false`；无通信协议或存储格式变化。普通浏览及更换表盘不将自动／轮播模式改成固定显示。模式、固定页、间隔、勾选和顺序写入失败时回滚，轮播至少保留一页，既有空列表进入轮播时启用原顺序的第一项。

The device presents three mutually exclusive modes with conditional controls: cycling, a fixed page, and automatic music/overview routing. It keeps the existing wire fields and NVS format, retains cycle selections/order/interval across mode changes, and stays in Settings until the user leaves. Failed writes restore the previous choices; casual browsing and clock-face changes do not replace automatic modes with a fixed page. Native/build evidence remains separate from installation.

## 2026-10-11：Codex 直达与设置返回一致性（本地验证）

Codex 直达与设置、应用详情复用同一左上角返回箭头：位置 `(30,12)`，触摸区域 `52×56`，使用 Montserrat 24 px 图标和公共按钮的默认／按下样式。标题统一放在返回按钮右侧 `(94,21)`，左对齐并使用 30 px 字号；直达保留专用内容布局。

直达打开时记录原页面、主导航及设置／应用详情的返回目标；关闭时恢复完整上下文。支持“总览 → 应用详情 → 设置 → Codex 直达 → 设置 → 应用详情 → 总览”，不会因临时进入 Codex 页面覆盖上一级目标。正在打开会话、录音或发送时沿用原有操作锁。

Codex Direct shares the existing top-left back arrow with Settings and app details, including position, touch area and button states. Its 30 px title is left-aligned beside the back arrow, matching Settings. A round trip restores the previous page and its navigation context, preserving nested Settings/detail back destinations and the original busy-operation lock. Native regression and firmware build results are separate from device installation.

## 页面结构

| 页面 | 原布局 | 新布局 |
| --- | --- | --- |
| 总览 | 多组模型、系统、国产模型摘要堆叠 | 左侧单行摘要，右侧可选 Codex、DeepSeek、智谱，按数量排版 |
| 模型额度 | 固定三个周期空仪表和账户资金 | 有效额度条、金色 PRO 描边徽章、独立重置时间/每张卡到期日期、近七天用量柱状图 |
| 天气 | 纵向字段 | 天气图形、大温度、今日温度范围、湿度和空气指标 |
| 行情 | 字段拼接 | 美股、港股、A 股三列独立滚动，按行情源 symbol 前缀归类 |
| 电脑状态 | 文字与曲线 | CPU/内存仪表，上传下载图例及真实采样曲线 |
| 音乐 | 小图和文字 | 大封面、标题/歌手层级、播放状态和有效进度 |

### 独立倒计时界面

时钟倒计时将设置与计时画面分开：设置页使用成组的时分秒控件和快捷时长，运行时只保留居中的 Montserrat Medium 192 px 数字。轻触显示操作，5 秒无操作后收起；暂停和到时保持控制可见，重置返回设置。该数字子集由同一字体脚本重建。

时钟标题栏与倒计时设置页使用同位置的「时钟｜倒计时」分段控件（284×56，x=96、y=12），浅蓝底表示当前页。切回时钟继续后台计时，重新进入倒计时保留剩余时间；运行时随标题栏一起隐藏。删除操作提示与日期设置持久化备注，保持计时和表单界面简洁。

日期倒计时设置采用统一的名称、目标日期表单卡片与底部保存按钮，中文输入时隐藏日期和底部操作。屏幕声音中的日期设置行仅在选中日期倒计时屏保时出现，音量区随展开／收起移动，类型保存失败保留原布局。两项倒计时不共享计时或配置状态。

# 0.2.34 顶栏与天气

USB、Wi-Fi、BLE 图标固定位置，物理连接时绿色，断开时灰色，移除下划线、圆点与感叹号。颜色表示连接状态；实际数据通道仍由有效心跳按 USB > Wi-Fi > BLE 选择。点击图标仍进入连接诊断。电池以绿色填充表示剩余电量，中央数字保持对比度，充电显示闪电，未知显示灰色与 `--`。

电池与时间之间增加扬声器入口：音量 0 或静音时灰色无声图标，其他情况显示白色扬声器，点击进入「声音」。音量滑块松手保存、静音切换后立即同步图标。

天气「逐小时」改为「24小时预报」：一条横向滚动温度曲线，每小时包含当地日期/时间、天气图标、温度与降雨概率。温度标签随曲线位置变化，缺失温度显示 `--` 并断开相邻线段，不把缺失值当零；平温使用最小 4°C 刻度范围。控件复用并保留横向滚动位置。未来 7 天视图保留。

降雨概率同时以等比例柱显示，0% 无柱、未知无柱但文字为 `--`。温度折线沿用网络图已验证的 raw-end 绘制路径，避免斜线端部蒙版裁掉线段，并以真实中间像素探针验证线条可见。电池与声音刷新独立于桥接快照，每秒检查一次；电池硬件仍每 2 秒采样。
