## 使用

- 顶部点页面可固定显示；“自动轮播”恢复自动展示。
- “模型额度”下拉框选择平台；账户授权和天气城市仍在电脑桥接配置。
- “设置”页向下滚动可调整轮播页面、顺序和屏保时间。
- 点击时钟依次切换经典圆盘、纯数字、轨道圆盘、奶油刻度、方形表盘并保存；右上角可恢复自动轮播。
- 总览右侧默认显示 Codex、DeepSeek、智谱。在设置页勾选显示的模型，至少保留一个；选择保存在 TAB5 本地。按量 API 显示余额和源提供的累计消费，缺失金额不补零。
- 桌宠保存在 TAB5 本地闪存，重启后直接恢复。只有缓存缺失、损坏或更换图片时后台同步；同步时显示进度。
- 三通道均报告已有资源 ID；日常只传小型状态数据。音乐封面缓存在内存，仅变化或设备重启后需要重新同步，避免频繁擦写闪存。
- 资源完整接收并校验后才显示；切换曲目期间不显示旧曲目的封面。不把用户私有图片打包进固件。
- 设备触摸及电脑键鼠均无操作默认 5 分钟进入黑底移动时钟屏保并降低亮度，设置可调整或关闭。首次触摸或电脑新键鼠操作恢复原页面和亮度；离线时钟在恢复连接后退出。

## 不属于本轮原有功能迁移

TAB5 语音、摄像头、远程执行电脑操作、OTA 是新功能；macOS TAB5 桥接尚未实现。
本轮不改变账户授权方式、不新增供应商轮询，不发布正式版本。

## 当前范围调整（2026-09-23）

- 按用户要求，其他模型每日用量/消费统计暂无需求，不列入待实现项；保留现有 Codex 每日额度增量。
- DeepSeek 复用现有网页采集与官方余额 API；API 更新保留网页消费值及其独立时间。凭据范围/币种变化清除旧消费；网页钱包与最近 API 钱包不一致时拒绝合并，超过 24 小时未更新的消费不展示。
- 网易云新增本地只读歌曲总时长回退，严格匹配歌名/歌手/专辑。尚未验证本地进度字段的实时性，因此不作为实时进度来源。TAB5 可显示已知总时长与未知进度，隐藏无法计算的比例条。
