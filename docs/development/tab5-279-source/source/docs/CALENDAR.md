# 日历与生日（0.2.26）

总览底部 Codex、DeepSeek、智谱卡片进入对应模型额度详情；日期/时间区域进入日历，天气区域进入天气详情。日历和天气从总览打开后，返回键回到总览。

日历支持上月、下月、今天和点选日期，月份按实际需要显示 4–6 周，仅补齐首尾周的相邻月份日期，不显示整周多余日期。公历数字和农历分行，今天金色边框，所选日期蓝绿色背景；节气、节日、休假、补班和生日分别标注。右侧显示所选日期及可滚动的近期生日。

## 数据与范围

- 农历在设备离线计算，月历浏览范围 1902–2099 年。`calendar_data.h` 通过 PowerShell Core 的 `ChineseLunisolarCalendar` 生成；生成器和独立参考检查均要求 Core，避免旧 Windows PowerShell/.NET Framework 的远期历法表差异。C 实现的 72,319 天公历/农历往返及逐日参考比较通过。
- 节气使用香港天文台的 2026–2028 年日历表，例如 [2026 年公历与农历日期对照表](https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T2026c.txt)。未提供节气表的年份不臆造节气日期。
- 中国大陆 2026 年放假和补班依据[国务院办公厅通知](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202511/t20251104_4258838.html)。节日与实际放假独立处理，其他年份显示「放假安排待更新」。
- 桥接通过既有鉴权状态协议附加 `calendar.detail`：`terms[{year,dates}]`、`holidayYear`、`holidays[{start,end,name}]`、`workdays[]`、`birthdays[{name,month,day,lunar,leap,remind}]`。原日期字段和旧设备协议保持兼容，缺少详情数据时农历仍可浏览。

## 生日管理

电脑托盘 → 内容设置 → 日历与生日。支持新增、修改、移除，最多 32 项，姓名 1–16 字，公历/农历、可选闰月、提前 0–30 天提醒。更改只有点击保存才持久化并同步，取消不会保存。

记录只保存在本机用户目录 `AI-bot/birthdays.json`，不写入项目、截图或发布材料。保存采用临时文件替换；加载失败时窗口禁用保存，防止覆盖原文件。布局测试使用隔离目录及虚构姓名。

闰月生日在没有对应闰月的年份按普通月份；缺少农历三十或公历 2 月 29 日时按当月末日。设备按同一规则计算下一次生日。提醒期间总览显示倒计时；开启通知后每天首次显示生日提示，点击进入日历，Codex 未读完成提醒优先。设备重新启动后可再次提示当天生日。

## 验证与限制

原生 LVGL 检查覆盖总览 5 个入口、所选额度同步、日期与生日、跨月、4/5/6 行布局、补班及未知年份。WinForms 检查覆盖常规/窄窗口、生日编辑、日期校验和取消。截图、数学参考数据、编译及协议结果在 `.tools/calendar-20260928`。

模拟截图中的「家人」「朋友」是测试数据，没有写入用户的生日配置。固件编译、模拟验证与真机验收分别记录；安装前不视为设备已具备本功能。
