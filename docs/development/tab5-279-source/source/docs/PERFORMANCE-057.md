## 实现

- LVGL PSRAM 局部缓冲由 64 行扩大到 256 行（按 1280 宽计算），仍为双缓冲及原旋转暂存。1220×516 主页面原先约 8 次分块提交，现在约 2 次；最终行数由 LVGL 对齐计算，不固定假设为 256。三块缓冲合计多使用 1,474,560 字节 PSRAM。
- 预旋转快照按源与目标地址递增复制，减少反向短行搬运；覆盖完整快照高度时合并为连续复制。快照完整性、缺缓存/回弹/弹窗回退、正常 LCD 提交和完成确认保留。
- 追加最近大帧的快照复制、DMA 等待、主动让出 CPU 耗时及总分块/原生缓存分块计数。用它们核对实际瓶颈，不仅以总耗时推测。保留原 47 列，新增索引 47～51，单位为 µs / µs / µs / 次 / 次；各项只覆盖 RENDER_START 至 RENDER_READY 窗口，不能与最终扫描完成等同。累计微秒计数差值使用无符号回绕。
