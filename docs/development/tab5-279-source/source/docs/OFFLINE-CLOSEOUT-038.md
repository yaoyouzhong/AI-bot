## 2026-09-29 真机验收顺序

1. 先保存当前诊断与桥接配置，部署本候选配套桥接，再由设备确认升级。读回 0.2.38、运行槽、镜像哈希和 VALID；确认无崩溃/显示欠载增长。保留供电，首次测试保留 USB 诊断。
2. 左右连续切页 15 秒，在“内容与轮播”上下滚动 15 秒；核对真实绘制、旋转/传输耗时、长帧及松手回弹。仍卡则按采样定位，不以模拟通过判定流畅。
3. OTA：0.2.35 安装本包使用旧升级引擎，不能作为 64 KiB 方案速度结论。确认本版稳定后再准备下一份版本明确、校验一致的测试包，记录从点击到重启可用的总时长，以及读取/写入/校验时间；同版本提示应消失。不在无人看护时自动发起后续升级。
4. 语音分别检查 USB、纯 Wi-Fi、纯 BLE；纯 BLE 必须选用 TAB5 麦克风，避免只测到大疆直连电脑。测试短句及 30–60 秒长句、结束返回草稿、取消、断线后重连；文字仍需手动发送。结束后在电脑通过大疆直接用豆包，确认恢复原音源。
5. 新完成 Codex 任务：总览优先提醒 → 打开正确会话及对应轮次正文 → 未读清零；运行时公开动态持续更新，空占位不误清未读。
6. 日历跨月多余行、右侧布局、“近期生日：无”、生日/农历/补班；天气 24 小时曲线与未来七天；声音/静音图标与音量听感；触摸/录音过程中不误入屏保。
7. 插拔 USB 检查电量不突跳；电量准确性需连续充放电观察。确认自动连接选择与用户原轮播配置恢复，不把测试设置留作默认。
