## 用户可见行为

- TAB5 缓存由 8 页增至 32 页，按会话、轮次、页码隔离并按最近使用淘汰。上一轮/下一轮使用真实相邻关系查缓存；缓存页无需再次请求。
- 桥接复用一次桌面 owner snapshot，批量返回当前页、同轮相邻页、已加载且结束的相邻轮次首段。不会为预取另开 IPC 请求，不主动加载整个未展开历史。离线日志回退仍保留原同轮邻页读取。
- 批量正文保持 16 KB 预算，超限逐项删减预取项；新 BLE 固件声明 packedReply 后可接收压缩批次。当前页内容不因压缩减少；不采用“每次只取一页”策略。
- 固定查看已有历史不再后台读取最新。回到最新时仍更新。缓存为内存缓存，设备或桥接 session 重启后失效。
- 等待未缓存内容期间，已缓存方向仍可点击；12 秒后释放导航等待并提示超时。底层在途请求仍可完成并填入缓存，旧响应不能覆盖更新的点击；该期限不等于网络传输提速。
- 连续 RPC 交互结束后的 3 秒窗口优先传电脑指标，较大的完整状态保持待发送，窗口结束继续发送。指标不冒充完整会话心跳，认证、nonce、防重放和发送行为不变。
- 桥接新增 RPC 数值诊断：排队、请求读取、服务处理、响应写入毫秒和字节数，不记录正文或凭据。
