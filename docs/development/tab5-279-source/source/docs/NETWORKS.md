# TAB5 多网络与连接诊断

## 使用

- 0.2.22 起电脑「TAB5 连接 → Wi-Fi」读取设备保存的网络列表，显示真实 SSID、备注与连接状态。选中后可改备注、更新密码并连接，或确认删除；新增单独使用「新增」。空密码连接会单独确认，避免误清空原密码。密码不会回读。未连接 USB 或固件版本不支持时显示错误，不伪装为空列表。

- 电脑「TAB5 连接」写入 2.4 GHz Wi-Fi 时，设备记住该网络并保留旧网络。最多 5 个；相同 SSID 更新密码，不占新名额；满额不悄悄删除旧网络。
- 设备「更多 → 设置」下方「网络与连接诊断」可选择已保存网络并连接，或重新连接。录音、拍照、发送期间不切换网络。
- 0.2.21 起可选中网络，点击「删除所选网络」，核对名称后确认删除。删除其他网络不打断当前连接；删除当前网络后尝试剩余网络；删除最后一个后断开 Wi-Fi，可继续通过 USB 配网。录音、拍照、发送、升级期间不允许删除。配对与 USB/BLE 配置不变。
- 支持 Wi-Fi 备注名。电脑「TAB5 连接」填写真实 SSID 与备注后，可随配网保存，也可点击「仅保存备注（无需密码）」单独修改；留空保存备注会清除备注。备注最多 48 UTF-8 字节（16 个汉字），不得包含控制字符。备注不改变 SSID、密码、当前网络或连接模式。
- 列表、诊断和删除确认显示备注及真实 SSID；内部仍以真实 SSID 定位，不用备注作为网络身份。
- 0.2.21 使用版本 2 的独立 `wifi_profiles2` 键，保存 SSID、密码与备注。启动时优先读取有效 v2（包括空列表），否则兼容导入 v1 `wifi_profiles`，更早版本才从 `config` 导入单网络；首次修改时保存 v2。配对 `config` ABI 不变。删除一次提交整个 v2 网络记录，不会在正常重启后从旧配置复活。
- 网络不可用时先重试；未找到 AP/认证失败约 10 秒后尝试下一个已保存网络，其他连接失败约 30 秒轮换。轮换只改 RAM，不在每次重试时写 NVS。
- 当前配对配置结构与 NVS `config` 键保持不变。名称/密码/备注不写入运行诊断日志。回退到 0.2.20 及更早固件只能读取升级前旧网络快照，不支持 v2 删除或备注。

## 自检含义

Wi-Fi 关联与 IP、电脑 HTTP/鉴权、设备配对、Codex 采集状态、语音启用状态分别显示。语音“已启用”仅表示电脑设置已启用，实际音频设备、豆包焦点和录音结果仍由真实录音验证；未知字段显示待确认。断线时不把旧电脑状态当作当前状态。

## 电脑地址变化

设备 Wi-Fi 已连接但桥接心跳过期时，每 10 秒至多一次 UDP 广播到 18766，接收等待最多 300 ms，运行于 Wi-Fi 工作线程。复用共享桥接的发现端口，不更改原小屏的协议。

请求为 `TAB5_DISCOVER_V1|deviceId|nonce|HMAC`；响应为 `TAB5_BRIDGE_V1|deviceId|nonce|host|port|HMAC`。HMAC 使用既有配对密钥，覆盖前面的完整 ASCII 文本。密钥和密码不出现在报文中。设备校验本次随机 nonce、设备 ID、响应源地址、端口及签名；只接受私网 IPv4。电脑仅返回实际绑定且和请求方同网段的服务地址。

此功能不能绕过路由器的终端隔离或防火墙；地址重新发现的模拟测试不代表跨真实无线终端已互通。

## 当前证据

网络配置纯 C 测试覆盖旧网络保留、同名更新、容量上限、损坏结构；桥接测试覆盖配对 ID、nonce、HMAC 篡改和原 LAN 协议。LVGL 实际事件覆盖选网入口、语音未启用/已启用及离开诊断页。家庭/办公两处网络的自动切换仍待迁移后真机确认。
