# 声音设置

从 0.2.33-ui 起，在 TAB5「设置 → 声音」中调整提示音量（0–100%）、静音和试听。默认保持原来的 35%；静音保留音量值，取消静音后恢复。滑动时更新数字，松手后保存；静音切换立即保存，重启后读取。保存失败显示提示并恢复控件到已保存值。

设置统一控制语音就绪提示、新回复提示音及语音播报；不改变 TAB5 或大疆麦克风增益，也不修改电脑音量。音量为 0 或静音时不可试听。试听只播放短音，不播报新回复文字；录音期间拒绝试听，开始录音会清除排队的试听。

音量与静音使用 `aibot_tab5/sound_v1` 独立 NVS 键，保持现有配对/config 数据布局。已有音频工作任务独占编解码器，UI 不操作 I2S 或功放；录音时沿用原来的编解码器初始化顺序，静音只阻止提示音输出。

验证：原生 LVGL 预览覆盖松手保存、静音后恢复音量、零音量、录音忙碌和保存失败。真实扬声器音量、录音回归及断电保存需要安装后验收，不能以预览替代。

0.2.35：用户确认 0.2.34 能听见短音但声音偏小。短音峰值从 2800 提升至 9000（约 +10 dB，仍保留约 11 dB 数字余量），音量与静音设置继续生效；不调整语音录音的 I2S 时钟或麦克风增益。试听成功后不再显示‘试听提示音’文字。新版响度仍需真机确认。
