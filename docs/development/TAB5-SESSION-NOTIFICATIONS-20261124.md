# TAB5 323-R2 会话提醒

2026-11-24。本地配对 TAB5 已安装 323-R2。设计和实现基于 0.2.322-ui 的 322-R6 固件，包含已有 R5 传输和 TF 组件覆盖及 R6 总览布局。相邻 TAB5 主检出保留其并行的未提交改动。可应用的源码增量见 [会话提醒补丁](TAB5-SESSION-NOTIFICATIONS-20261124.patch)。

## 界面

在「对话」页选中 Codex 或 Claude 会话，行尾显示铃铛。点击直接切换，设备保存成功后更新图标。静音会话即使未选中也显示划线铃铛，可以直接恢复。沿用深色会话卡片，铃铛使用 24 px 图标、52 × 52 px 的独立触控区。未读角标留在同一会话卡内，Claude 的来源标签与角标并排。长标题仍可截断，右侧输入区和录音电平沿用原布局。存储失败保留原状态并提示重试。

## 行为与兼容

- Codex 和 Claude 分别按现有会话 ID 保存到 TAB5 的 NVS，各可保存 64 条关闭规则。已有固件配置默认为提醒开启，恢复提醒保留已累积的未读。
- 新回复照常进入原有未读队列，角标和读回复确认仍沿用原流程。呈现横幅和安排提示音前检查规则。同一批有其他会话的新回复时，横幅与声音取自仍开启提醒的会话。
- 等待操作事件使用当前会话状态。桥接只提供客户端汇总、没有可核对的会话身份时，如果当前目录还有该客户端的静音会话，暂缓这条汇总横幅。已不在目录且与活动会话无关的旧规则保留，其他汇总横幅恢复。具有明确身份的回复继续按各会话自己的设置提醒。
- 复用 Windows 和 macOS 桥接已有的对话状态、未读和会话标识，无需更改桌面桥接或消息格式。连接 Mac 时使用相同的 323-R2 固件。设备上的全局任务提醒继续决定是否呈现横幅和播放提示音。

- 323-R1 的精确镜像从 ota_0 启动。隔离的 USB 夹具在 Codex 和 Claude 分别验证行尾触控、静音保留未读、另一会话的新回复横幅，以及列表排序后点击移动了的划线铃铛恢复提醒。复测截图保存在本机的 `hardware-captures-restoration/`。
