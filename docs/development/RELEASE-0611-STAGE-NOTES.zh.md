## 未发布 Windows 语音焦点修复 - 2026-10-27

- 修复后台额度窗口置顶及交互后切回后台时抢走输入焦点的问题；后台显示保持不激活，交互窗口保留最小尺寸约束。
- 录音增加有界焦点恢复和音频暂停，确认豆包已经停止时避免重复停止；中断文字保留供核对，不自动发送。增加后台窗口焦点、语音音频排空和停止状态回归。
- 后续无字复验修正：有声音时不再将豆包暂时空闲视为最终空结果；保留完整文字等待和麦克风选择，超时显示诊断错误并保留电脑草稿。增加不记录内容的音频时长、文本更新计数和识别状态诊断；偶发全程无字的原因仍需实机定位。
- 对豆包主动提前停止收音增加状态检查，立即停止后续音频转送并提示文字可能不完整，保留已有文字；不再继续显示可以说话。此保护不等于解决输入法提前结束的原因，连续录音稳定性仍待验收。
- 首轮候选仍在第二次 TAB5 实机录音时失败；新修复不能以构建和窗口回归代替实机验收。Mac 豆包模式同样依赖焦点，但后台刷新未发现相同置顶逻辑；本次未改 Mac 或固件。详见 [排障记录](WINDOWS-VOICE-FOCUS-20261027.md)。

## 未发布 Mac 模型账号对齐 - 2026-10-26

- 股票名称图集改为逐行独立绘制，避免 macOS 14 下跨行栅格化差异，保持已验收的字体、颜色、字号和对齐方式。同步分页历史测试夹具，隔离测试注册默认值，并为异步菜单检查设置有界等待。

- DeepSeek API 总余额（已含赠送）与网页消费独立存储、计时并标明来源。分开模式下设备仅接收 API 余额，不合并未经核实账号归属的网页消费；纯网页模式可同时显示该来源的余额和消费。网页充值与赠送钱包按币种使用十进制合计，不重复累加权威总余额。
- 从官方控制台 `total_costs` 读取消费；同一网页来源仅更新余额时保留消费原时间，最多显示 24 小时。来源、凭据或币种切换防止旧 API 数据被标为网页数据；读取失败保留各自最近成功数据。
- 对齐 Windows 股票名称的绘制参数：21 像素常规字重、20 像素行高、右对齐、灰色文字，长名称使用末尾省略号；去掉额外上下留白。股票代码已共用固件 16 像素 Font2。配套本地 ESP8266 0.5.6 候选保留重置卡数字细笔画，并在缩小的方框内分列对齐。
- 将模型账号改为左侧 14 家厂商、右侧官方网页登录与额度来源设置的统一窗口。保留 API／本地服务来源，并补上 DeepSeek 官方网页余额读取。
- 系统 WebKit 存储管理网页登录状态；已选择网页来源的账户在窗口关闭后和桥接重启后继续尝试刷新。登录失效、限流和网络失败保留最近成功数据，界面显示更新时间和旧缓存状态；不导出 Cookie 或混算账户余额与本机 token。
- ESP8266 天气地名按实际字形宽度适配，股票中文放大至现有行高；独立 ESP8266 0.5.4 本地候选修复 Codex 重置卡边框和动画避让。TAB5 固件不变。
- 后续反馈：天气右上角改为与 Windows 对齐的彩色空气质量徽标及独立天气文字；模型账号增加每厂商网页缩放，便于操作超出视口的官方弹窗。ESP8266 0.5.5 本地候选按用户偏好将重置卡文字由 16 缩到 14 像素。
