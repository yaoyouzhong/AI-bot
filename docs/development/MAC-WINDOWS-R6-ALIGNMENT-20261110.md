# Mac 对齐 Windows R6（2026-11-10）

## 范围与显示行为

来源 `origin/codex/windows-dynamic-microphone-20261105` 的 `020d248978d011a3a9169a46dca09d11fe47e168`，包含此前 Mac 项目合并和 LIST1 改动。Windows 交接见 [MAC-HANDOFF-FROM-WINDOWS-20261110](MAC-HANDOFF-FROM-WINDOWS-20261110.md)。协议、会话 ID 和草稿格式不变。

Mac 检测到某个完整回复的桌面未读标记后，该标记在同一账号与本地主机的有效快照中消失，即在下一次桥接同步确认该轮已读。未观察到对应未读标记时沿用 5 秒稳定窗口；上一轮遗留的未读标记不能立即清除新回复。读取失败保留已确认的结果，不根据缺失状态新建已读；账号、轮次、时钟回退及其他会话分别隔离。

界面继续使用现有 TAB5 未读角标、颜色、字号、行尺寸和点击区，不增加控件。确认发生时让该回复的角标消退；R6 固件自行处理列表中未读项的排序和触控结束后的定位，桥接不切换厂商、项目或当前会话。
