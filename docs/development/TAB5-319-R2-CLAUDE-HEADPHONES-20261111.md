# TAB5 319-R2：Claude 工作动画换成原版耳机六帧

旧项目 `esp8266-ai` 的 `5f52a39` 在 Claude 为 `working` 且画面正在显示 Claude 时才推进这组动画，间隔 120 毫秒。319-R2 沿用该含义，只有总览和 Claude 屏保的工作状态选择新素材。空闲、等待、受阻、完成、离线等仍使用 319-R1 的素材和时序。

保持两处的状态文字、布局、背景和触控交互。动画使用共同裁切边界，保持原有帧间位移。总览内使用 1.5 倍缩放，屏保内使用 4 倍缩放，分别沿用当前萌宠的中心位置。工作动画每 720 毫秒循环一轮。

原版 APET 为 111×120、6 帧，SHA-256 `8c9e76f5f42e041ecd135df5c060dc29f6c69eb5ec6ec6cc6c15381d22fc03e5`。转码将纯黑背景键为透明，保留原版黑眼睛，裁切至公共边界并补偶数步幅。保留 254 种可见 RGB565 颜色。106×67 帧使用 11,080 字节压缩流，加调色板和帧索引共 11,862 字节。用户确认可随 TAB5 固件公开分发，见[素材归属](../../licenses/companion-art/NOTICE.md)。

在 [319-R1 补丁](TAB5-319-R1-RECENT-WORKSPACE-20261111.patch)之上应用 [319-R2 补丁](TAB5-319-R2-CLAUDE-HEADPHONES-20261111.patch)。从已获授权的原版 APET 生成构建素材：

```powershell
python scripts/package_claude_headphones.py --input <claude-legacy.apet> --output firmware/main/claude_headphones_data.inc
```

生成头文件的 SHA-256 为 `e3be2cbac23df48a2cde61e2bdece24abb3470387da659296aecbdb133cb088b`。本地候选编译使用这一份素材，源码补丁包含转换器和来源说明。未提供该输入的独立源码构建会继续使用原工作素材。

固件构建、图库栈预算、绘制后端和正式升级加载器校验通过。BIN 7,056,016 字节，SHA-256 `705683e3bfe3f9979f3b361c83c7a287341813c351bb412fff83dc2b37e49fa3`；ELF SHA-256 `3ba127dd7592e64d3a15665249e000a37436b799d4957fd46987b3a0b1106161`。应用分区余量 `0x25570` 字节。正式本地升级入口为 `artifacts/firmware/tab5/latest/aibot_tab5.bin`。
