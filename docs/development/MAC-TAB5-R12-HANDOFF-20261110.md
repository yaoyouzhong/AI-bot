# Windows → Mac：TAB5 R12 与桥接对齐

## 范围与源码

用户要求修复图标边缘像素差异、提交并通知 Mac 对齐。共同协议版本保持 `0.2.318-ui`、协议字段不变；Windows 特有的 UAC、托盘和 DPAPI 实现不移植。最终双平台发布仍须在同一源码提交上各自构建和验收，不能把 Windows 测试当成 Mac 验收。本文与相关源码随同本地提交；远端同步状态以实际推送为准。

TAB5 源码增量依次为 R4 基础源码、仓库已有 LIST1、R5、R6 补丁，再依次应用 [R8](TAB5-318-R8-CODEX-COMPANION-20261110.patch)、[R10](TAB5-318-R10-CACHE-BANDWIDTH-20261110.patch)、[R11](TAB5-318-R11-OTA-PREPARATION-20261110.patch)、[R12](TAB5-318-R12-WORKSPACE-ICON-20261110.patch)。R7 时钟试验和 R9 诊断不纳入。每一步先 `git apply --check`；保留 Mac 自己的未提交修改，不覆盖本地工作。
