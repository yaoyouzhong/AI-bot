# Windows 语音设置对齐 Mac（2026-11-02）

## 实现前设计

- 使用场景：用户在设备中心选择下一段录音的麦克风；打开设置只读取元数据，不录音、不切换输入法或系统默认设备。Mac 参考为 `MacVoiceSettingsWindow.swift`、`MacVoiceMicrophone.swift`。
- 信息层级：标题“语音输入”及“保存后用于下一段录音”；其下为识别方式、单一录音麦克风选择器；再下为“收音状态”，分别说明预期音源和识别服务；底部常驻状态与“刷新设备／取消／保存”。不增加第二个启用开关。
- 布局：560×480 逻辑像素，最小 520×420；外边距 24、组间距 16、标签宽 90、下拉框占剩余宽度，行高至少 32。主体可纵向滚动，底部操作固定；长设备名在下拉框中截断并提供完整名称提示。
- 字体与颜色沿 Windows 设置样式：Microsoft YaHei UI 9.5 正文、17 标题、10.5 分组；白底、Ink #202B3B、Muted #586577、Accent #226DD7、Surface #F6F8FB、Border #D3DAE4。只突出保存按钮。
- 交互状态：后台加载禁用保存；刷新保留编辑选择和不可用原设备；保存前再次读取设备并核对设置基线，取消、关闭、录音开始、设备拔除或并发配置变化均不得写入。明确选择的设备断开时不改用其他设备；自动模式多个 DJI 时要求用户明确选择。
- 平台边界：Windows 当前识别后端为豆包输入法，以固定识别方式展示；Mac 本地识别、Mac 授权按钮和恢复机制不机械移植。Windows 增加系统默认麦克风的动态解析；旧 `DjiId`、快捷键与设置文件保持兼容。
