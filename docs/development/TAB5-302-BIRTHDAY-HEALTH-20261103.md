## 设计与实现

- 近期生日只展示从今天到未来第 30 天（含当天和第 30 天）的最多三条，保持排序、农历计算和界面布局；其他生日仍保留在日历格、选择日期详情和提醒中。无符合项仍显示“无”。
- 告警点击锁定所点击的来源并直接进入对应详情，显示桥接提供的异常摘要和检测数据；遇到检查信息暂缺时保留匹配告警的内容。恢复后显示对应检测正常，不被其他并发告警替换；当最新检测明确正常时去掉该告警，保留其他告警和任务通知优先级。
- Windows 桥接上，同一受影响通道收到一次真实成功即确认恢复；不让其他通道成功掩盖失败，仍保留有限窗口内的重连历史。该更改已部署到 Windows 桥接；TAB5 设备 UI 随后经用户授权刷入 0.2.303-ui，启动核验结果见下文。
- 事发现场曾读到 `Codex 连接不稳`、近期异常三次；点击详情误入未确认检测的逻辑缺陷和恢复门槛均有代码依据，但未能重放用户当时的精确时序，不能声称已证实唯一触发路径。后台后来报告连接正常且无活动告警。
