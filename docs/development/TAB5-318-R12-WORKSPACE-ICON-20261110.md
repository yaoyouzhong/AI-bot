# TAB5 318-R12：对话页图标边缘一致性

## 问题和方案

R8 和 R10 的真实 LVGL 缓存聚合回归在横向滑动时出现 12 个 RGB565 像素的色阶差异，位于 Codex 会话切换图标边缘。差异与总览屏闪没有证据证明是同一原因。图标缩放时，带抗锯齿的即时渲染和分段缓存绘制在裁剪边界产生不同插值舍入；临时关闭抗锯齿后回归通过，但图标明显粗糙，因此未采用。

保持原图标大小、中心、按钮布局、颜色及交互。用真实 LVGL 将原有项目图标的两种缩放尺寸预渲染为透明图像，运行时以原尺寸显示，避免不同分段再次缩放。仅对两个现有 Codex/Claude 工作区按钮启用；其余通用测试按钮保持原有行为。生成器 `scripts/generate-workspace-brand-scaled.py` 使用 `TAB5_BRAND_ASSET_GEN_ONLY` 的实际 LVGL 输出，并用 LZ4 压缩；未引入新来源素材。两种图标尺寸生成结果可重复，实际对话页与 R10 基线整帧逐像素一致。

## 同版本升级后的核验等待

R12 安装时，用户报告“核验启动”按钮长时间不可点。原桥接在最终传输后保留 90 秒 OTA 租约；同版本重装不能用相同版本心跳当作完成，因此仅靠版本不会提前释放租约。设备已重启后，这会继续阻止核验。代码修复只在传输最后一块已释放、没有活动传输，且新的已配对 USB 主机状态应答证明设备在最后一块之后重启、OTA 当前空闲时提前释放占用；不自动认定升级成功，仍须核验精确 ELF 和分区。无可靠新证据时保留原保护超时。

针对新/旧设备启动时间、错误设备、宿主、序列、未授权连接、OTA 仍忙和传输未结束的拒绝，以及真实加密 HTTP/RPC OTA 既有回归和 Windows Release 构建通过。此改动仍需在后续真实升级中记录按钮恢复耗时；不为计时重复刷机。无线独立通道未新增提前释放策略，不声称无线单独连接也已优化。
