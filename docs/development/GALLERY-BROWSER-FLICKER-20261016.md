# 图库翻页闪屏修复

## 原因与修改

用户在安装新版浏览器后报告左右翻页明显闪屏。现场实现中，LoadDetailAsync 每次先调用 ClearDetail，销毁旧图片、切换到加载标签，完成读图和解码后再显示图片；全屏的 UpdateNavigation 又在请求前、加载中、完成时重复 CopyImage 与 SetImage，重置视图并触发额外重绘。

- 同一作品翻页时保留当前图片和资料，新 JPEG 完成加载、解码并通过取消令牌检查后才一次替换。切换作品、空结果等状态仍明确清理旧内容。
- GalleryImageView 记录图片修订号，全屏只在修订号改变时复制新图片；单纯的导航状态更新不复制图片、不重置缩放。
- 箭头状态没有改变时不再重复触发全屏图片重绘。
- 读取下一页失败时保留上一次成功图片，恢复对应页码并显示“翻页失败，请重试”。快速连续请求仍取消过期结果。
