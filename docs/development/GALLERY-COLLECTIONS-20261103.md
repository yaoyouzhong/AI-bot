# 图库范围与画质切换（2026-11-03）

## 使用语义

- 年度和全量决定作品范围；普通和高清决定电脑浏览时采用适配展示图还是高清素材。TAB5 使用相应范围的适配展示图，画质选项不改变设备图片。
- 运行时使用一套全量图库和对应高清素材；年度范围由其中的有序 `annual-index.json` 指向全量作品。旧版年度包没有 `collection` 字段，按年度识别；新全量标准包声明 `collection: full`，高清完整包的内置标准包采用相同标记。年度交付包可以从全量素材和年度索引另行生成；已有全量图库时，导入年度包不能覆盖全量图库。导入过程保留旧年度图库备份和旧高清素材，后续须单独核实并清理。
- 高清素材缺失或与展示图不匹配时回退普通图。切换范围会改变每日作品序列及其内容摘要；协议格式不变。
- 需要单独交付年度包时，`scripts/package_annual_hd_from_full.py` 从已安装的全量普通目录、高清素材目录和年度索引，生成独立的年度普通 ZIP 与年度高清 ZIP，逐项校验源文件及生成包；不要求日常另存一套年度图片。只需普通包时可用 `scripts/package_daily_art.py --collection annual`。

## Windows 与 Mac 交接

- Windows：`GalleryPreferences` 保存选择；`DailyArt`、`DesktopArt` 分别保存普通展示图和高清素材。现有图库对象按所选范围读取全量目录或年度索引，图像质量可独立选择。
- Mac：`MacTab5Gallery` 使用同一图库目录，`MacGalleryManager` 提供相同选择。导入全量包时校验年度索引，浏览器在选择变化时刷新。
- 不在安装过程删除已有图库或备份；完成全量覆盖核验后，另行判断旧年度副本的清理。全量包验收应以实际包和 SHA-256 为准。
- Windows 本机已安装基于 0.6.16 的图库候选并重启，进程与状态接口正常；这不是公开发布原包。名画全量 1,765 件、书法全量 929 个作品标识，每类年度索引 366 件；安装后名画 4,044 个标准文件及 1,979 份高清素材、书法 7,170 个标准文件及 2,591 份高清素材均逐项通过 SHA-256 核验。当前选择为年度与高清。
- Windows 图库界面删除年度索引备注、线上标准版信息和重复画质状态；年度模式显示索引的实际作品数，高清素材缺失时保留提醒。离屏界面及更新、导入和切换自测通过。
- Mac 原生构建、自测与界面渲染、TAB5 真机同步均待对应环境验收。图库修改尚未推送或公开发布。

## 数据来源与边界

历史普通图库 1,765 件名画和 867 件书法的原图与页面映射已核验；当前年度版每类 366 件。年度书法有 62 个作品标识不在旧全库中，全量候选保留这些标识，不能仅凭名称断定其与历史作品是否重复。全量合并优先采用当前年度版已有内容；缺失年代的历史书法显示“年代未详”。高清素材的实际清晰度受各自留存原图分辨率限制。

书法 `colbase-tnm-TB-1743` 的历史版有 5 个展示页，正式年度版根据来源记录移除了其中 1 个空白装裱细节页，保留总览与其余 3 个细节页；全量候选沿用这 4 页并保留其来源原图。名画 `cma-1954.369` 的现行年度高清素材是原始巨幅 TIFF 的缩小分发副本；全量候选改为保留 83,933 × 4,868 的原始 TIFF，并按等比例映射恢复对应页面。Windows 隔离测试已验证总览原图解码；Mac 原生读取仍待验证。

## TAB5 范围切换同步问题（2026-11-03）

- 设备旧逻辑按每个类别使用同一对同步游标文件；切换范围后继续保存会覆盖另一范围的进度，图片按作品顺序定位，原全量目录与年度索引顺序不一致，降低共用效果。电脑候选将年度索引排在全量顺序之前，年度版本摘要保持不变；全量版本摘要随顺序变化。
- 设备候选按完整内容摘要分别保存两份校验游标，并保留旧游标对用于离线和兼容；第一次写入前迁移旧游标。当前旧固件只能保留当时尚未被覆盖的游标，无法重建已丢失的历史进度。代码与测试补丁见 `TAB5-GALLERY-SCOPE-SYNC-20261103.patch`，候选基于 `TAB5-302-BIRTHDAY-HEALTH-20261103.md` 记录的 0.2.303 本地源码快照。
- 游标和文件复用不等于首次切换不做任何检查：已有的全量旧顺序改变后需重新核验，年度与全量的共同图片只有位置与内容摘要一致时才能避免重复下载；已完成的作品和页面会先验证已保存的数据；单张图片的下载续传文件仍按类别共用，切换过程中未完成的单张图片可能需要补传。磁盘游标测试已覆盖交替切换、断写、旧格式迁移及离线恢复。硬件刷写与真机范围切换验收尚未完成。
