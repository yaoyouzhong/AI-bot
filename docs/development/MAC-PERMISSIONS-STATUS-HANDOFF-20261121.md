# Mac 系统授权提示

## 问题与设计

使用场景是打开新版应用时核对已有权限，或从设备中心补办权限。授权列表保留 AppKit 现有浅色、深色系统配色、字体和窗口尺寸。每行从左到右显示权限名称与用途、当前状态、唯一可用的操作。状态使用现有 112 点列，操作沿用至少 32 点高的原生按钮。授权完成后隐藏相应操作。底部保留「稍后完成」和在 Finder 定位当前 App 的入口。

「辅助功能」区分当前进程未授权、辅助功能已授权但输入待确认、两项均可用。系统设置里可能仍保留旧版临时签名的条目，因此只在当前进程未获信任时提示核对 App。「系统事件自动化」在首次启动及升级检查中单独处理，辅助进程短暂退出时允许重新启动并向系统查询，只有系统确认可请求时才弹出授权。两项分别显示实时状态和对应操作，任何一项都不会因另一项待授权而被跳过。

## 跨平台交接

本次只改 macOS 的系统授权提示及 System Events 预检。Windows 没有这组 macOS 权限，设备协议、配对格式与固件不涉及本次变更。

验收覆盖首次和覆盖升级窗口、未满足及部分满足状态、已授权时隐藏操作，以及 System Events 短暂未运行后的授权流程。验收应检查默认与最小窗口的实际渲染，并区分应用读取到的当前进程权限与 macOS 设置中显示的历史条目。
