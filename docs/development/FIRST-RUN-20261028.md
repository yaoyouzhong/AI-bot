# Windows 首次使用改进与验证 · 2026-10-28

用户选择改善“全新环境安装 → 设备发现 → 配对／权限 → 首次显示”，并确认没有备用出厂设备，要求保留现有设备配置。本轮实现电脑端接入引导与文档修正，在独立 Windows Sandbox 验证安装和启动；不重置现有设备，不把隔离测试视为实体首刷验收。

## 改动

- 空设备中心解释 USB 接入顺序，区分已有 AI-bot 和出厂设备；账号、语音及无线可在显示正常后配置。
- 添加窗口分别说明“验证并添加”和首次安装，始终显示连接状态、安装帮助及关闭操作。沿用现有白色背景、蓝色按钮和 Microsoft YaHei UI。
- 无端口时禁用验证；多个端口要求选择；刷新按 USB identity 保留选择，支持 COM 改号。选中设备消失时不自动换到另一台；扫描失败清除旧端口。
- TAB5 首刷检查通过后的返回按钮随入口变化：从添加进入时返回添加，从维护页进入时仍返回 USB 配对。启动验证门槛不变。
- 安装指南按设备当前状态分流，补充第一次连接的完成标准、运行时下载失败的处理与按功能配置 Mac 权限；修正旧版解锁入口、Mac 支持范围和 TAB5 轮播说明，中英文同步。
- 保留此前明确要求的安装时自动配置解锁组件，不修改安装器策略、系统安全策略或设备协议。
