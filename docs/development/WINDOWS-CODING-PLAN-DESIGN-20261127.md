# Windows 国产编程套餐设计

本轮只做本地代码、模拟接口和渲染验证；真实订阅在用户开通后验证。不发布、不部署、不修改固件。

## 用户行为与界面

设备中心 → 账号数据 → 模型账号，延续现有左侧厂商、右侧授权页布局。右侧标题下增加“统计内容”选择，同一厂商的套餐、按量余额／指定资源包分开，切换后展示对应缓存，不换算、不合并。

用户确认：显示、额度徽标、厂商卡片副标题及下拉选项中的套餐名称只写 `Coding Plan` / `Token Plan`，不重复 GLM、Kimi、MiMo、百炼等厂商或模型名前缀。厂商名称保留在独立标题。Step Plan 在用户界面归为 Coding Plan，MiniMax M Plan 归为 Token Plan；来源与技术文档仍保留官方产品名便于追溯。既有缓存输出时同样规范化。

- 智谱：GLM Coding Plan、API 余额；Coding Plan 可以保存个人版套餐 Key。
- 百炼：Coding Plan、Token Plan；登录相应套餐页。
- MiniMax：M Plan / Token Plan，复用订阅 Key，兼容已有字段。
- 小米：MiMo Token Plan，登录套餐管理页。
- Kimi：保留现有 Kimi Code 用量服务与网页登录。
- 火山方舟、腾讯、百度、阶跃、华为：明确套餐产品与官方页面；只读取页面上带明确周期和已用比例的套餐进度，不能用云余额代替。
- DeepSeek：保留按量账户路径，不新增未经证实的自营 Coding Plan。

布局保持左对齐，Microsoft YaHei UI 9pt 正文、13pt 标题；白色 #FFFFFF 内容区、#F5F7FA 导航、#1E293B 标题、#64748B 辅助文字、#2563EB 主按钮。统计内容行使用自动高度和 12px 间距，下拉框至少 240×32，按钮至少 108×36。凭据行保持密码输入与“保存并测试”主操作。较窄窗口允许换行，不压缩网页缩放和刷新按钮。

状态区直接列出本次统计产品、5 小时／周／套餐已用比例及更新时间。无数据提示登录相应套餐页；失败保留最近成功值，明确缓存状态。切换余额／套餐时不复用另一种统计口径的数值。

## 数据契约

智谱 Key 查询依据官方 zai-org/zai-coding-plugins，仅个人版；保留 TOKENS_LIMIT 窗口，排除 MCP TIME_LIMIT。阿里识别 codingPlanInstanceInfos 中唯一 VALID 订阅的 codingPlanQuotaInfo，独立保存三个窗口。不能将 Token Plan 的固定天数套给 Coding Plan 的订阅月。

其他网页登录适配不假装有公开 Key 额度 API：在精确官方 HTTPS 主机与套餐路由内提取可见的、有明确周期名称的套餐进度。归一化协议由本应用定义；同周期多个互相矛盾的读数拒绝更新，不读取页面任意余额、Token 累计调用量或无标签百分比。真实页面不满足可识别结构时显示失败，等待真实订阅核验后调整。

缓存只存显示数据；Key 保存在 Windows 凭据管理器。背景刷新继续遵循已启用且已配置的数据需求。新厂商先在 Windows 模型账号窗口使用，不增加设备显示模式或修改协议。

## 验收

Release 构建、--status-once、隔离额度自测；覆盖鉴权、错误体、歧义、零用量、周期、缓存重载和套餐／余额切换。离屏渲染检查模型账号在 100/125/175% 下的布局及已有额度页。新增厂商的网页登录端到端与真实设备显示不计作已验收。
