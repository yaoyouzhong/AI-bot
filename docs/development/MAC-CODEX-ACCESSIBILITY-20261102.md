# Mac Codex 直达辅助功能授权引导

场景：首次启用直达或替换桥接后权限未生效。Codex 会话设置页的“桌面直达”区域依次显示开关、用途说明、实时授权状态和打开辅助功能设置的次级按钮；授权后自动刷新状态，再由用户在 TAB5 重新定位。沿用现有系统字体、12 点次级文字、页面间距和原生按钮，默认及最小窗口尺寸可滚动。授权仍由用户在 macOS 系统设置中决定。辅助功能状态不代替目标会话核验。

首次引导：用户确认所有可用功能默认开启。启动时直达、任务发送、电脑控制和音乐控制默认可用；已保存的明确关闭选择保留，语音沿用本来已开启的实现与原麦克风选择。普通应用首次启动且直达已开启、权限未生效时，申请一次 macOS 原生授权；已授权或明确关闭时不请求，拒绝后不在每次启动反复弹窗。开关由关闭改为开启时仍可主动请求。授权状态及手动打开系统授权设置的入口留在设置页；旧记录已勾选但未生效时提示重新添加当前应用。设备请求和离线诊断不弹窗，不自动发送、不绕过目标核验。系统弹窗由 macOS 控制；账户、设备配对、系统权限和解锁密码仍需对应真实条件。

当前设备通用 409 文案无法区分权限问题，旧固件保持兼容。本改动仅改善 Mac 设置页；设备侧明确提示、首次使用入口发现性及正式签名下升级授权保持，仍需独立设计和验证。临时签名包的实际升级授权行为不能仅凭状态推断。

隔离原生界面回归覆盖授权／未授权两种状态及浅色／深色、默认／最小尺寸；实际查看默认浅色、默认深色和最小深色预览。最小尺寸通过滚动访问下方内容。尚未进行新安装系统授权、设置链接或 TAB5 真机验收；本地代码尚未安装到当前运行的应用。

引导候选完成 macOS 411 项 XCTest、29,059 项隔离检查及 Release 构建；Release 自身的离屏界面回归通过，已查看最终未授权浅色预览。原生系统提示和实际授权跳转尚未在全新安装环境验收，系统可能因已有记录或用户此前拒绝而不再次显示提示，仍须验证手动入口及实际定位。

默认开启候选：macOS 412 项 XCTest、29,059 项隔离检查及 Release 构建通过；默认值、明确关闭保留、授权提示一次性条件和既有音乐设置迁移通过隔离回归。完整本机应用包构建及签名校验通过，包内离屏 UI 回归通过，已检查未授权页面。未替换或重启当前应用；尚未对新包执行正常启动、系统授权弹窗、音乐自动化／播放控制或 TAB5 真机验收，以上结果不代表新用户完整验收通过。

现有安装包的现场恢复：用户确认系统页面显示“设备控制与数据访问”，原条目已勾选；关闭再开启后定位仍为 409，后台仍显示权限未生效。用户移除旧条目并添加 `/Applications/AIBotBridge.app` 后，TAB5 定位返回 200，后台确认目标任务和主输入框，用户确认可用。这证明本次重新关联后定位恢复，不证明失效根因或新代码已经安装，也不代表录音／发送验收。
## 0.6.15 正式包升级引导补充

最终临时签名候选的钥匙串一次授权及同包重启已通过，但用户定位仍失败，当前进程诊断明确为辅助功能权限未生效。旧实现仅保存全局“提示过”，导致新构建失去权限后不再引导。

设计：沿用 macOS 原生辅助功能请求及已有功能页的授权状态与入口，不新增应用弹窗或改动设备布局。正常启动在功能开启、权限未生效且当前签名构建尚未请求时发起一次系统引导；同一构建不重复提示，已授权或用户关闭功能时不请求。用公开的代码签名摘要识别构建，无法取得时使用包版本及源码标识回退；旧布尔标志不能抑制新构建引导。系统仍由用户授权。检查最终功能页实际预览，并在最终安装包验证新构建引导、同包重启及设备定位。
