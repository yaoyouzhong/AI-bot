## 电脑备注

备注按不可变 host ID 存入独立的 `host_labels1` 版本化 blob，不改变原可信电脑、配对密钥或蓝牙 bond 的布局和证明。USB 正常上报原电脑名不覆盖备注；名称在选择列表、状态条与电脑控制页一致显示。留空保存恢复原名。

使用独立中/英文输入法编辑，保存失败保留输入与旧名称；取消清除本编辑器未提交拼音，不影响 Codex 草稿。损坏的备注记录不会覆盖原信任数据，命名保存会被拒绝，显示回退为原名。

## Mac / Wi-Fi Codex 直达卡住

用户报告无线来回切换会话后停在“正在同步会话，请稍后再按语音键”，电脑实际已切到前台；确认通道为 Mac/Wi-Fi，Mac 调试侧也指向固件。

修复使用已认证的桌面确认直接选择任务，保持当前本机草稿的保存保护。直达页打开时，较旧的目录不再清除已确认目标；停止发起隐藏任务页的新读取/草稿请求，仍处理已在途的请求，不伪造完成或清空标志。快捷语音不再等待无关的隐藏编辑器同步，但仍要求已确认的目标、有效桥接会话与新鲜状态；待确认消息继续拦截。录音、回填和发送仍由用户分别触发。
