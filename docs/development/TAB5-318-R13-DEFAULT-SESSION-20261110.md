# TAB5 318-R13：最近会话的列表可见性

## 问题与处理

发布前完整 LVGL 回归发现，重新进入对话后，按更新时间自动选中了列表第 11 条会话，但列表仍停在顶部，选中项不在视野中。R12 隔离复现时，选中 ID 以 `108` 结尾，首屏最后一个绑定的 ID 以 `106` 结尾，滚动位置为 0。

R13 复用已有的列表位置恢复逻辑，将默认选中的会话带入视野；未读提升仍由现有规则处理，保留布局、尺寸、字体、颜色和点击区域。实际离屏渲染中，原先不可见的选中项完整显示在列表内。实现和测试增量见[源码补丁](TAB5-318-R13-DEFAULT-SESSION-20261110.patch)，其 SHA-256 为 `bda70deaa7ef6f7f0ddac23017598e68060a94fc38fd46c11bf22cabcc930451`，在 R12 源码上 `git apply --check` 通过。

完整回归还发现旧测试假定回复返回按钮位于固定子节点、把不在客户端目录中的虚构会话计入可见未读数、以及在总览页直接模拟对话页按钮；测试夹具已改为指向真实返回控件、提供符合规则的合成目录、先进入对话页。断言继续检查目标行为，没有以跳过错误来取得通过。
