# TAB5 本地自动验收设计（2026-11-04）

用户明确要求提供自动操作 TAB5，便于后续自动验收。本功能用于已配对设备的本地诊断：后台截图、点击、滑动和只读探测；不打开或置顶电脑窗口，不新增应用内授权开关或设备设置页。首次实现限定已认证 USB，Windows/Mac 使用同一可选 v1 契约；旧固件忽略字段。

## 场景与交互

自动验收工具显式运行期间才发布短时命令，默认桥接不发自动触摸。先取得真实截图和设备报告的逻辑宽高、方向，再按该坐标系操作。1280×720 与 720×1280、0°/90°/180°/270°均须严格匹配；与截图缩略图坐标不能混用。点击经正常 LVGL 输入路径保持约 80 ms；滑动在 100–1200 ms 内插值，并在结束、超时、断连或方向变化时释放触点。已有按钮层级、字体、颜色、尺寸、间距与触控区域不变，不添加屏幕控件。

手工触摸、升级/照片传输或屏保等状态下不得让未确认的手势落到另一页面；测试工具通过当前截图决定是否只执行唤醒并重新探测。工具结束清空命令、释放串口并恢复原桥接；本次脚本返回进入前页面，验证展示设置未变。不能将触摸应答单独当作页面行为通过，必须检查真实设备截图和实际读取结果。只读阅读验收不执行任务发送、中断、账户操作、升级或重置；这些能力需要所属具体任务的授权。

## 共同协议

已认证 USB 状态帧的 `connectionHealth.uiAutomationCommand` 为可选对象：`version=1`、`requestId`（32 位随机 hex）、`transport=USB`、`expiresAt`（不超过帧时间 5 秒）、`op=probe|tap|swipe`，手势另带 `width`、`height`、`rotation`（0/1/2/3，LVGL 枚举）、`x`、`y`、`toX`、`toY`、`durationMs`。帧新鲜度和既有设备/电脑身份认证、序列号及所有权规则继续有效。每个请求 ID 至多执行一次；失去归属或时效后不能继续按压；不接受文字、路径或系统命令。

USB hello 的可选 `uiAutomation` 是 `1,requestId,status,width,height,rotation`；status 为 1 运行、2 已结束、3 拒绝、4 取消。电脑仅匹配当前请求 ID，忽略迟到或其他请求，设备未知/拒绝不能自动重发点击。probe 只报告视口，不触摸屏幕。电脑收到手势结束后再采集真实画面判断结果。

## 验证

离线验证严格字段、超时、防重复、方向与范围、释放及实际 LVGL 按钮/滚动；Windows/Mac 对同一命令和应答合成数据回归。先编译及实际渲染检查，再部署有摘要的本地固件，保留展示设置。真机验证完整的后台截图、点击打开 Claude 阅读、分页、滚动和返回，并区分离屏、设备截图与物理触摸手感的覆盖范围。编译和截图不证明触摸面板手感。
