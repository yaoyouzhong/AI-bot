# TAB5 总览客户端选择设计（2026-11-04）

用户要求 Claude 各状态及 Codex 的大小、位置一致。总览沿用 Codex 的主体中心线（卡片局部 x≈610、y≈134）和现有标题/状态/按钮，不移动 Codex。Claude 按主体而非含透明边距、道具的画布归一化：身体中位宽度约 126px，接近 Codex 常态约 132px；不同原图的长宽比保持不变。行走 5.75 倍、滑板 5.5 倍、其他 5.25 倍，使 Claude 各组主体宽度约 126–126.5px；采用每组固定身体中心锚点对齐，保留原始浮动/跳跃动作，不逐帧追踪导致抖动。总览容器向左扩 2px、增宽 4px、向上扩 24px 且保持下边界，为道具留空间；主体中心不变，屏保尺寸与定位保持原样。所有 378 帧检查边界、各状态实际渲染及 Codex 对照后再进行真机验收。

身份事件接入沿用上述区域、尺寸和控件：绑定的工作状态、名称和最近活动时间来自同一会话；失败投影为现有 `error`，使用已有受阻萌宠与文案；确认中断后投影为空闲，清除完成标记；仅收到 Stop 的不确定状态使用现有未知状态。明确的最终成功结果复用完成动画。没有新布局、按钮、颜色或触控区域；仍用真实 LVGL 的六状态预览核对，再由 TAB5 真机验收。独立交互 Claude 会话缺少通用最终结果或中断事件时保持未确认，不能显示成功。受控任务运行入口仅提供给命令行，不改用户现有 Claude 设置。

延用 0.2.312 总览与萌宠屏保的布局、字体、动画、颜色、触控区域和状态文案，不新增控件。总览只显示一只所选客户端萌宠，关联的会话必须属于同一客户端；只选 Codex 或只选 Claude 时，活动状态不改变选择，离线显示对应未知或离线状态。两者都选择时，优先等待，再选工作中，双方同级或都不活跃则用可用的真实最近活动时间，平局或时间不可比较沿用当前选择。自动模式保持活动优先；屏保选择独立不变。没有真实 Claude 会话信息时显示客户端名称，不冒用 Codex 会话。

Claude 分支沿用现有 480 像素标题区域、y=68 的位置、原字体、颜色、控件间距和操作按钮；有经过会话绑定的名称时上方说明为“最近会话”，标题显示该名称，没有名称时说明为“当前客户端”、标题回退“Claude Code”。桥接端在 Claude 工作或等待且无法绑定当前任务身份时不发送名称。名称最多 120 个字符，设备沿用现有标题截断策略；长标题、中文及无名称回退仍须在真实生产 LVGL 预览中检查，不能由代码检查替代。
