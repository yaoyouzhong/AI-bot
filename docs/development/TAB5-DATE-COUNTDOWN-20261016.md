# 日期倒计时界面、语音与日历选择（2026-10-16）

后续字体与输入框布局调整见 [矢量字体与紧凑表单记录](TAB5-DATE-COUNTDOWN-FONT-20261016.md)。本文保留首次实现与构建证据，字库和镜像哈希不代表后续最终候选。

## 本轮范围

- 统一左右布局：左侧标题／随标题延长的横线／目标日期；右侧天数与单位保持共同基线，数字组按位数在右侧区域居中。
- 名称最多 10 个 Unicode 字符，按实际文字宽度缩放。输入和保存均校验；整段超长粘贴或语音完整拒绝，保留原名称，不截断。旧存储名称仍可读，修改保存适用新上限。
- 07:00–19:00 日间配色，其余夜间；未来、当天、已过日期分别显示“还有”“就是今天”“已过去”。
- 编辑页名称右侧麦克风；复用现有 voice_remote 接口、独立 owner/generation，沿用日程的 DJI 优先／切 TAB5、停止、等待识别、静音提示、垃圾桶取消、错误恢复及光标处回填。结果不会自动保存或发送。会话归属变化后不会误停止其他录音。
- 目标日期改为月历，支持年月下拉、前后月、日期选择、闰年与月份天数校正。确定仅修改编辑草稿，保存才写入 NVS。
- 与其他页面共用左上角箭头。返回依次关闭日历／键盘；录音期间先取消录音并保留输入。

## 字库与容量

新增 OFL 字库和生成脚本，来源及源文件哈希见 TAB5 THIRD_PARTY_NOTICES.md。标题使用词库权重选取的 1,000 个常用字和 ASCII 衬线子集；含其他字的标题整行回退现有 UI 字库，避免缺字和混排。受设备点阵字库限制，短标题放大后的细节不等同于先前生成效果图。

最初的 3,755 字子集使分区仅余 22 KiB，已被替换，未部署。最终镜像 7,010,288 字节，应用分区余 198,672 字节（约 194.0 KiB）。构建仍提示应用分区剩余约 3%，后续新增资源需继续核对容量；本次没有修改分区。
