# TAB5 固件更新日志

TAB5 与电脑桥接、ESP8266 分别编号。`versions/TAB5` 登记待发布版本；发布前必须与镜像内版本和说明 sidecar 一致。

## 0.2.234-ui - 2026-10-19

### 蓝牙核验与显示连续性

- 修复 BLE 启动报告刷新时出现小数毫秒的问题，原桥接现可核验精确 ELF、VALID 分区和三份已认证实时样本，健康阈值不变。保留报告忙碌时的有界重发及跨核心跳读取顺序修复。
- 单次瞬时采样异常保留近期可信电量，短暂读取失败更快补采，启动立即读取。确认缺失或过期仍清除估算，保留冷启动充电校准；用户确认重启后很快显示、USB 插拔显示正常。
- 包含 229／230 的电脑解锁、音量拖动恢复及双向 Codex 已读同步。TAB5 实际打开匹配回复后清除电脑未读状态，预取不误标。

### 验证与兼容

- 原版 Windows 0.6.10／c608 的一次隔离纯 BLE 核验在 9.34 秒后确认精确 .234 ELF、ota_1 VALID 和三份实时样本，无隔离违规。保留此前已通过的实机项目，不重复验收；电脑 WLAN 已恢复。
- 原生线程与实际 c608 线包回放、完整原生界面、962 项对应源码、首刷擦除区域及许可包摘要均通过。截图为隔离夹具，真机证据另记。保留配对、PIN 和展示设置，首刷与升级包不能混用。
- 完整已读同步和解锁使用 Windows 0.6.10；Mac、ESP8266 与图库保留原发布版本。详见 [发布说明](../RELEASE-0.6.10.md)、[BLE 根因](TAB5-BLE-UPTIME-20261019.md) 和 [电量验收](TAB5-BATTERY-DISPLAY-20261019.md)。
