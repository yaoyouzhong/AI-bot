# TAB5 固件更新日志

TAB5 与电脑桥接、ESP8266 分别编号。`versions/TAB5` 登记待发布版本；发布前必须与镜像内版本和说明 sidecar 一致。

## 0.2.131-ui - 图片解码缓存同步

- 在 JPEG DMA 解码前写回并失效画廊输出缓存，防止旧缓存覆盖新像素；同步失败保留已显示画面。
- 新增尾部缓存故障模型及连续分页逐像素检查，保留 .130 的方向行为。已安装并通过精确镜像启动核验，用户确认花屏解决，原自动轮播已恢复。见[验收记录](../TAB5-ACCEPTANCE-131.md)。
