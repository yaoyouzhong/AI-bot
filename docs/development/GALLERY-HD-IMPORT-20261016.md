## 实现
- 图库管理独立显示“基础图库”和“高清素材”状态。“安装基础图库…”与“高清画质（可选）→添加高清素材…”分区，避免两个导入入口混淆。
- 接受 hd-materials-20261016-delivery 的现有两份 ZIP，无需手动解压或修改路径。
- 基础图库仍提供作品目录、导读、分页与展示页。高清包是电脑画质增强包，尚不能替代基础图库独立使用；未安装基础图库时明确提示先安装对应图库。已有图库无需重装。
- DesktopArt 独立目录存储；逐文件流式 SHA-256、完整清单、路径/重复文件/符号链接/容量/索引边界校验，全部通过才原子切换 category.current。取消或失败保留旧版本，移除本次暂存目录；成功替换后旧版本保留。
- 现有浏览器在下一次加载图片时读取新版本指针；导入后返回作品即可启用。缺图、损坏或展示图哈希不匹配时回退标准图。原本机开发索引仍保留为未导入类别的兼容来源。
- 不修改 DailyArt、TAB5 文件、设备传输或固件。
