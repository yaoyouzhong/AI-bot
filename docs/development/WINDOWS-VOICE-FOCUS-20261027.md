## Mac 代码对照

- `MacDoubaoSpeech.safeFocus` 依赖桥接处于活动状态、录音窗口为 key window、编辑器为 first responder，并核对锁屏、安全输入和输入法。`tick()` 每 100 毫秒执行，失焦直接终止录音。因此 **Mac 豆包模式存在类似失焦中断的可能**。
- `MacDomesticQuotaWindow.tick` → `MacDomesticBrowser.tick/reload` 更新网页和状态；这条后台刷新路径没有 Windows 的 `TopMost` 调用，也没有主动激活窗口的对应操作。显式打开账号窗口才调用 `makeKeyAndOrderFront`／`NSApp.activate`。
- `MacTab5Speech` 的本地识别通过 Speech/AVFoundation 处理音频，不依赖上述编辑器焦点检查。
- 这是源代码核对，未在本 Windows 环境运行 Mac 构建或实机录音，不能据此宣称 Mac 已通过稳定性验收。建议 Mac 豆包连续录音覆盖后台额度刷新，检查中断与末句完整性。
