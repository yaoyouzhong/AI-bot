## 修复范围

- 桥接保留 250 毫秒原始采样，上传／下载数字统一使用最近四个采样的 1 秒均值；每个采样更新，CPU／内存仍按原 2 秒间隔更新。
- Windows 镜像、TAB5 和 ESP8266 曲线使用相同均值，数字取当前曲线末端；移除额外的三点平滑及设备播放延迟。
- TAB5 新数据整批同步显示，保留缺失采样断点、重复包去重、会话重置、真实原始流量和纵轴缓慢收缩。
- ESP8266 收完批量采样后同时画数字和曲线，新采样会话清除旧历史；保留数字绘制降级、串口速率及 USB／Wi-Fi 回退。
- 用户确认 Chrome 网页播放此前一直正常，保留该验收基线；新增助手能力及其他播放器版本另行记录，不扩大本次网络修复范围。

## 已完成验证

- Windows Release 构建：0 警告、0 错误；完整 `--self-test-public` 通过。
