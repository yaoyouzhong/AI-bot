## 后续隔离边界

- 保持旧版固件和桥接供用户正常使用。新仓库只进行本地编辑、编译、离线预览和自测；再次刷写/切换实际使用版本前另行确认具体候选。
- 不通过修改版本号、收到 USB 帧或测试素材有数据宣称完整迁移。旧版展示、数据源、用户设置、资源、操作路径均需分别对齐。
- 预览命令不打开串口、不启动 HTTP 服务、不修改设置。未知命令现在显式退出 2，避免误启动新桥接。
- 编译后执行预览前必须检查编译退出码，不能在失败后继续运行旧的构建产物。
