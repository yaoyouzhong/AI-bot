# AI-bot 0.6.20 与 TAB5 0.2.320-ui

## 下载

从[正式发布附件](https://github.com/yaoyouzhong/AI-bot/releases/tag/v0.6.20)或[下载中心](../DOWNLOADS.md)获取 Windows x64 安装器、Mac Apple Silicon ZIP、TAB5 首刷或升级包，以及名画和书法精选图库。

## 图库下载

普通版可直接下载 ZIP。Windows 或 Mac 高清版下载并解压[高清图库下载工具](https://github.com/yaoyouzhong/AI-bot/releases/download/gallery-2026.11.12.1/AI-bot-HD-Gallery-Downloader-2026.3.zip)，选择名画或书法，下载、合并和校验后，在桥接程序中手动导入完整 ZIP。详细步骤见[高清图库指南](GALLERY-HD.md)。

## 桌面桥接 0.6.20

- 改善 TAB5 的 Wi-Fi 发现、状态同步、触控核验和固件更新后的自动启动核验。Mac 串口重连后会恢复设备识别。
- Windows 和 Mac 改善和风天气自动定位、区县匹配和权限恢复后的刷新。查询失败时保留最近天气。
- Mac 新增系统授权窗口，说明天气定位和 Codex 会话直达的系统权限。已验证覆盖安装、配对与设置保留，以及现有账号授权后重启复用。独立新账号首次授权流程尚未实测。

## TAB5 0.2.320-ui

- 改善总览连接状态、日历和天气。已验证本版的 USB 和 Wi-Fi 升级、启动核验与设置保留。
- 首刷包和升级包使用同一份已实测的固件。首刷包已通过离线校验。总览长测曾记录一次 LCD 欠载，随后观察未见计数增加。[固件与对应源码](https://github.com/yaoyouzhong/AI-bot/releases/tag/tab5-v0.2.320-ui)

## 366 精选图库 2026.2

- 名画和书法各 366 件。普通与高清包均含新版导览、逐件赏析及出处。书法精选附可读正文、节录或核实参考。
- 高清包各分 2 段，提供下载合并工具及校验清单。包版本为 `2026.11.12.1`。

## English

Windows and Mac bridge 0.6.20 improve TAB5 discovery, Wi-Fi control, post-update boot verification and location-aware weather refresh. macOS adds a permissions window for weather location and direct Codex conversation navigation. Upgrade, restart and permission recovery were verified on an existing Mac account. First-time authorization in a new account remains untested.

TAB5 0.2.320-ui refines the overview, calendar and weather. USB and Wi-Fi upgrades passed on a physical device with settings retained. Both installation ZIPs include the tested firmware. The factory ZIP was verified offline. One LCD underrun was recorded in an overview test, and the counter held steady during subsequent observation.

Artwork edition 2026.2 updates the guides, sources and readable calligraphy texts for 366 paintings and 366 calligraphy works. Both standard and HD collections are available. Each HD archive is distributed in two verified parts. [Downloads](https://github.com/yaoyouzhong/AI-bot/blob/main/DOWNLOADS.en.md)
