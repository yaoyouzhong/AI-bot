## 无需用户协助退出

Windows 新增 `AIBotBridge.exe --exit`（诊断也可通过 `dotnet AIBotBridge.dll --exit`）。当前用户、当前 Windows 会话的命名事件通知 UI 线程调用原 `ExitThread()`，走与托盘退出相同的资源清理流程。返回 `BRIDGE_EXIT_REQUESTED` 只表示请求已发送，维护操作必须另等进程结束并确认串口释放后再编译/刷写；`BRIDGE_NOT_RUNNING` 表示没有可通知的新版实例。它不退出旧版 AIClockBridge，也不强制结束进程。

实际验证：PID 67448 接到退出请求后正常结束，随后独占打开 COM7 成功；已关闭串口探针并重新启动新版 PID 61228，8765 状态接口正常。未要求用户再次退出。
