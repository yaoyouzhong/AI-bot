## 已实现

- 已启用 ESP8266 时，托盘左键弹出小屏画面预览，否则打开“我的设备”。空设备显示添加引导；单设备显示详情；双设备提供列表和独立详情。
- 功能按登记型号显示，离线仍保留；设备名称、型号、连接状态与已观测版本分开展示。ESP8266 旧协议没有固件版本号时明确标注，不生成假版本。
- TAB5 专属连接、配网、语音、生日、OTA 与首次安装入口；ESP8266 专属亮度、页面、轮播、屏保、镜像、桌宠和刷机入口。两种新设备均可从添加引导进入各自首次安装，再经协议验证后登记。天气位置、股票、账号与额度历史归公共设置。
- 添加经过协议回执确认。USB 名称只作为线索；取消/失败不留下启用记录。每种型号最多一台。
- 设备注册表采用原子替换及上一版本备份；迁移幂等、移除后不自动恢复；坏文件及未来版本不覆盖。TAB5 原配对自动导入；明确的原小屏连接配置需用户确认导入。
- 新增 ESP8266 使用 USB 实例标识做兼容绑定，COM 改号不会绑定到占用旧端口的其他 USB 设备；旧配置保留兼容方式，不宣称拥有固件级稳定身份。
- 设备服务独立取消与释放；改名/改数据需求不重启另一台；LAN 路由动态关闭。串口发现避开 TAB5 USB，并在枚举暂时失败时重试。
- 数据采集按启用设备和电脑额度历史需求合并；取消不需要的采集，保留缓存。TAB5 所选厂商不再通过 ESP8266 页面间接决定。
- 停用与移除保留用户内容，产品内移除确认明确对象。录音、识别、升级、安装忙碌时禁止移除。旧窗口关闭后不能继续控制已经移除的目标。
- 保留的 TAB5 配对与新设备不同：添加引导要求单独确认替换，原 DPAPI 文件以带时间的 `.bak` 保留。普通移除不会执行替换或清除配对。
- `--tab5-pair` 转到设备中心引导；`--tab5-offer-ota` 要求启用且配对的 TAB5；`--flash` 要求启用 ESP8266。诊断/模拟命令继续保留。
