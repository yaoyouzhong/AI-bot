# 0.2.71 蓝牙照片与 OTA 提速

2026-10-01 接续“接续未完成项目验收”：用户目标为蓝牙照片从点击添加到附件成功小于 3 秒，并缩短实际 OTA。0.2.71 固件已安装且用户报告启动核验通过；提前授权窗口的首版桥接真机失败，已撤回，071b 修正版真机 18/18 通过。照片 3 秒与新 OTA 接收器实际收益尚未验收。

## 本轮改动

- **已撤回实验**：命令 3 提前授权下一个 8 片窗口。虽然模拟回归通过，真机第二个 48 KiB 块在 13440 字节处中断。修正版完全恢复原窗口实现；未确认是设备通知资源还是其他队列竞争，不能将推断写为根因。保留原窗口、精确字节和最终 ATT 确认。
- 大 RPC 接收时，状态流最多延后 3 秒，让通知与授权优先；语音轮询保持，状态不会无限延期。照片质量、加密、防重放、手动发送及固定通道选择不变。
- TAB5 批量蓝牙连接参数由请求 7.5～15 ms 改为请求 7.5 ms，仍由电脑决定是否接受；link 诊断中的实际间隔才是运行证据，空闲恢复原参数。
- OTA 保留两个 64 KiB PSRAM 接收块与接收/写入并行。在内部空闲至少 160 KiB 时尝试申请一个 64 KiB 内部暂存块，保留至少 96 KiB 余量；失败沿用旧 PSRAM 输入。此处针对本地 ESP-IDF 5.4.2 `esp_flash_api.c` 中 SPI1 外部内存输入的 32 字节搬运循环，让内部输入走原 8 KiB 分块，保留 SDK 锁、让出调度、64 KiB 擦除边界、哈希及启动验证。未改 SDK 或系统配置。
