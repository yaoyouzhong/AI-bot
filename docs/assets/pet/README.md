# AI-bot 桌宠素材 / Pet artwork

这一版保留用户选定的尖顶蓝紫像素形象、平直墨镜与电脑中央的 Codex 标识。

- `AI-bot-mascot.png`：1254×1254 透明静态母版。
- `AI-bot-mascot.gif`：256×256、6 帧、2.4 秒循环，轻微呼吸、键盘动作与墨镜反光扫动。
- `AI-bot-mascot.license.txt`：来源说明，与 GIF 放在同一目录。

下载并解压 `AI-bot-pet.zip` 后，可右键托盘图标 → ESP8266 小屏 → 外观设置 → 桌宠动画 → 通用 → 选择动画，选择 GIF。无需修改程序或刷固件；导入是用户主动选择，会改变本地桌宠设置。素材的图片解析与六帧转换已使用现有 Windows 导入代码核验，设备实际显示需另行确认。

本轮只更新截图与视频中的设计展示，不改变当前程序、固件或已有个人桌宠。静态母版与动画帧为本项目生成；电脑上的 Codex 标识不属于项目 MIT 授权范围。

## English

The selected pointed periwinkle pixel mascot is provided as a transparent 1254×1254
PNG and a six-frame, 256×256 looping GIF (2.4 seconds), with subtle breathing, keyboard motion and sunglass reflection sweep. Keep the same-name license notice beside the GIF. Extract the ZIP
and select the GIF through ESP8266 → Appearance → Pet Animation → Common → Select Animation. The existing
Windows importer has been checked; actual device display remains unverified.
This optional import changes your selected local pet, not installed program or
firmware defaults. The Codex product mark is separate from AI-bot's MIT artwork.
