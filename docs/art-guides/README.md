## 展示与操作 / Presentation and interaction

沿用现有绘画深色与书法纸色：绘画 `#111516 / #edf0e9 / #929a96`，书法 `#e7e0d1 / #332e27 / #776e60`。作品始终保持原比例；导读横屏使用右侧窄栏，竖屏在作品下方排字。正文为中文宋体标题、清晰无衬线文本。资料页面包含简介，仅在有权威赏析时出现欣赏提示，有可靠原文时出现释文。

翻页采用边缘留白中的细线箭头、小页码和回到第一页图标，无底色、无按钮外框。点击范围为56×56原生像素，视觉图标只占19～22像素。约2.8秒无操作后控件淡至低对比度，操作或键盘焦点时变清晰，避免“先点画面唤出控件”与触碰退出冲突。不叠加新的作品日期、装饰图形或醒目色块。

Artwork keeps its aspect ratio and existing category palette. Pagination uses thin monochrome arrows and quiet page numbers in the margin, with larger invisible hit targets. Controls fade after inactivity and remain visible for keyboard focus.

已明确的行为约定：

1. 翻页、回到作品第一页、打开详情、切换详情章节和“返回作品”均为屏保内部操作。
2. “返回作品”回到进入详情前的查看方式、同一作品、同一方向和同一分页，不跳到下一日作品。
3. 回到作品第一页不是返回TAB5系统主界面。触碰作品画面其他区域退出屏保，回到系统主界面；详情正文阅读、章节选择和返回按钮不退出。网页预览以“屏保已退出”模拟这一步，不冒充已连接的设备主界面。
4. 固件接入时需要处理按钮事件与屏保全局触摸唤醒之间的关系；仅停止LVGL事件冒泡未必能阻止输入层触发退出，必须沿真实触摸主链路验证。
5. 进入详情/手动翻页时，自动分页和日期切换需避免打断阅读；返回后恢复自动屏保策略，具体时机在固件接入时落实。

Reading and paging must not wake the system UI. Returning from details restores the originating view, orientation and frame. A separate exit action leaves the screensaver. Firmware integration must verify the input layer as well as widget event handling on real hardware.

预览的“现有作品页”逐字节复用当前横竖屏JPEG与分页，竖屏按现有编码方向旋转显示。界面层只覆盖留白内已经烘焙的旧局部计数，使用一套统一页码；JPEG本身不改。正式接入应由渲染器直接省略旧计数，并保留全幅/局部语义。“导读画面”使用当前已核实的主来源及裁切重新排版，是第一阶段布局样本。未来接入时导读需随完整帧列表使用，不能以主来源缩图替代整件长卷或完整册页。
