# AI-bot 0.6.21 与 TAB5 0.2.321-ui

从[正式发布附件](https://github.com/yaoyouzhong/AI-bot/releases/tag/v0.6.21)或[下载中心](../DOWNLOADS.md)获取 Windows、Apple Silicon Mac 和 TAB5 软件包。[安装指南](INSTALL.zh.md)

- 更新名画和书法时，只传变更的详情。书画屏保直接使用卡上已有的相同图片。
- USB 同步失败时，如果 Wi-Fi 已连接，TAB5 会更快切过去继续同步。
- 改善部分 TAB5 屏幕左侧偶尔闪一下的问题。
- Mac 升级后首次启动可能会弹出钥匙串提示。

## English

Get Windows, Apple Silicon Mac and TAB5 packages from the [release assets](https://github.com/yaoyouzhong/AI-bot/releases/tag/v0.6.21) or [downloads](../DOWNLOADS.en.md). See the [installation guide](INSTALL.zh.md).

- Gallery updates send only changed details. The artwork screensaver reuses matching images already on the card.
- If USB sync fails, TAB5 switches sooner to Wi-Fi when it is connected.
- Reduce occasional flicker on the left side of some TAB5 displays.
- macOS may show a Keychain prompt the first time you open the updated app.
