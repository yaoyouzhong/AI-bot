# AI-bot 0.6.21 与 TAB5 0.2.321-ui

从[正式发布附件](https://github.com/yaoyouzhong/AI-bot/releases/tag/v0.6.21)或[下载中心](../DOWNLOADS.md)获取 Windows、Apple Silicon Mac 和 TAB5 软件包。[安装指南](INSTALL.zh.md)

- Windows 和 Mac 支持批量压缩传输书画导读及完整原文分页。TAB5 在 TF 卡保存逐件摘要。仅详情变更时，屏保可以复用经校验的原图。
- TAB5 缩短 USB 图库传输失败后切到已就绪 Wi-Fi 的等待，ST7121 使用 CPU 分批复制显示数据。首刷包与升级包使用同一 R5 镜像。真机核对 Wi-Fi OTA 后的运行指纹与有效分区。
- Mac 原包已验证从 0.6.20 覆盖安装并启动。首次启动可能需要钥匙串授权。

## English

Get Windows, Apple Silicon Mac and TAB5 packages from the [release assets](https://github.com/yaoyouzhong/AI-bot/releases/tag/v0.6.21) or [downloads](../DOWNLOADS.en.md). See the [installation guide](INSTALL.zh.md).

- Windows and Mac can send compressed batches of updated guides and complete original-text pages. TAB5 stores per-work digests on the TF card. For guide-only changes, the screensaver can reuse the verified JPEG.
- TAB5 switches to available Wi-Fi sooner after a USB gallery transfer fails. The ST7121 display uses small CPU copies. First-install and upgrade packages use the same R5 image. The running image and valid boot partition were verified after a Wi-Fi OTA on hardware.
- The Mac package passed an upgrade from 0.6.20 and startup. The first launch may require Keychain authorization.
