# Windows / Mac 桥接 0.6.19

[English](#english) · [下载中心](../DOWNLOADS.md) · [安装指南](INSTALL.zh.md)

在电脑桥接的「设备中心 → 桥接设置 → 软件固件」检查更新并选择 ESP8266。有对应 SHA-256 校验文件时，桥接优先选精简刷机 ZIP；以 ESP8266 0.5.8 为例，下载约 384 KiB。缺少精简包或其校验文件时，仍可使用同版本的完整固件材料包。下载校验完成后，仍需由你打开原有刷机工具并确认写入。

本次只更新 Windows 10/11 x64 和 Apple Silicon Mac（macOS 13+）桥接。ESP8266 仍为 0.5.8，TAB5 仍为 0.2.318-ui，已安装的设备固件与可选图库无需更换。详见[软件与固件更新](UPDATES.md)及[完整更新日志](../CHANGELOG.zh.md#0619---2026-11-11)。

## English

[Download center](../DOWNLOADS.en.md) · [Installation guide](INSTALL.zh.md#english-quick-start)

Check for updates in Device Center → Bridge Settings → Software/Firmware and select ESP8266. The bridge prefers the compact flash ZIP when its matching SHA-256 file is available. The ESP8266 0.5.8 compact ZIP is about 384 KiB. If the compact ZIP or its checksum file is missing, the bridge can still use the full materials package for the same version. After verification, you still open the existing flash tool and confirm the write yourself.

This update applies to the Windows 10/11 x64 and Apple Silicon Mac (macOS 13+) bridge apps. ESP8266 stays at 0.5.8 and TAB5 at 0.2.318-ui. Installed firmware and optional artwork packs do not need to be replaced. See [Software and firmware updates](UPDATES.md) and the [full changelog](../CHANGELOG.md#0619---2026-11-11).
