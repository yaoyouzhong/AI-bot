# 0.2.76 主页连续复制与松手帧优化

## 实机依据

0.2.75 已通过 USB 启动核验，用户反馈“有提升，但还不够丝滑”。四页普通/预旋转缓存均已备齐；三个命中缓存的 629520 像素样本仍为 28545/31365/32292 µs，其中复制为 25278/27473/27599 µs，旋转为零、每帧两块。显示错误/欠载/看门狗均为零，空闲 PSRAM 约 12.6 MB。原始记录和限制见 [0.2.75](PERFORMANCE-075.md)。

## 修改

- 局部缓冲从 1280×256 扩大到 1280×512。1220×516 的主页视口可完整放入一块；预旋转快照由两轮逐列复制改为每个可见页面一次连续复制，正常双页过渡最多两次 memcpy。双绘制缓冲及旋转暂存合计额外 1966080 字节 PSRAM（1.875 MiB）。缓存容量及六 MiB 预旋转分配余量不变，沿用原 LCD 提交/完成/缓冲所有权。
- 对内容仍有效的预旋转快照，允许在吸附动画结束后绘制最终位置。原实现即使快照完全有效，也因动画标记已删除而回退到普通绘制和旋转。只有真正横向手势才允许复用旧内容；内容更新、按压反馈、缺失快照、遮挡和边缘空白仍按原条件回退。
- 不改变触摸阈值、惯性、页面布局或系统调度设置。Windows 继续使用已验收的 074c。
