# 本地界面更新 / Local UI update

TAB5 0.2.154-ui 已由用户在设备上安装，USB 实机启动核验通过；用户确认四字设置分类及十二月历行书显示正常。未公开发布。

- 十二月历保留三种原字体。文楷、马善政保持 24 px，志莽行书为 28 px；字库为 4 位灰阶，墨色加深，竖排基线间距为 33 px。原诗词、花卉及右侧日历保持。
- 设置左侧统一四字：网络连接、屏幕声音、内容轮播、固件升级、设备信息。
