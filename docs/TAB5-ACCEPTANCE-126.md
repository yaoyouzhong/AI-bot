# TAB5 0.2.126-ui 艺术屏保自动竖屏

用户要求横屏保持现状，设备竖起来时增加竖屏欣赏。范围仅为每日名画和每日书法；花卉台历、其他页面和横屏素材保持原样。

## 实现与资源

- BMI270加速度判断重力方向，连续稳定一秒后切换；支持两种竖放方向，平放、斜放、晃动和失效读数不触发切换。使用Bosch BSD-3-Clause官方驱动，来源和完整许可随独立TAB5工程保留。
- 813件作品增加1902张竖屏排版，先按720×1280排版，再旋转为兼容现有传输与解码的1280×720 JPEG；原1902张横屏图片SHA-256全部不变。
- 竖幅画作保持全幅并放大，标题、作者、馆藏及已核实中文备注移到底部。横竖切换不改每日作品顺序或分页；暂时无法取得另一方向时保留原画面。
- 最多缓存两张解码画面；触摸退出、屏保亮度恢复和常规页面坐标保持原行为。
- 固定包：`artifacts/firmware/tab5/latest/aibot_tab5.bin`，7,205,008字节。
- SHA-256：`9f4e89305d1b94796716bca836994fd18853729938d0da1b2365abf783cb708c`。
- ELF SHA-256：`5978181cd8ddf18d1181d602990984bb72b28af59ff0e8c379c5d530cd485a41`。
