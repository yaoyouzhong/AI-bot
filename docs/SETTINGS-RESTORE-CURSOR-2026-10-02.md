- D5 未通过：用户报告恢复成功但自选股票编辑器仍显示测试值。恢复写盘和运行态刷新使用新 `BridgeSettings.Load()`，而 `TrayApplicationContext.ShowSettings` 将启动时的旧 `_settings` 再次传给新窗口，构成确定的陈旧读取路径。不能由“恢复成功”判定界面验收完成。

- Microsoft 对 [CURSORINFO](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-cursorinfo) 和 [ShowCursor](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-showcursor) 的定义用于区分隐藏、触摸/笔抑制与显示计数。

## 修改

- 自选股票编辑器默认在创建时重新加载配置；托盘入口不再传启动快照。显式测试/预览仍可注入配置。
- `PointerVisibility` 在本桥接 UI 线程处理鼠标移动后，通过应用 Idle 检查指针当前所在的可见控件。只在指针隐藏时恢复该控件的光标；若设置形状后仍隐藏，最多恢复 16 次显示计数，达到可见即停止。已显示、触摸/笔抑制、外部应用、透明语音窗及窗口非客户区不处理，不更改 Windows 鼠标设置。此为已观察到症状的恢复措施，真实用户复测尚待执行。
- 未修改 TAB5 固件或配对数据，也没有代用户重新导入备份。真实股票恢复仍须在更新后重新打开编辑器核对，必要时再用 D4 原备份仅恢复股票。
