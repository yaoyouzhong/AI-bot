# 会员标识与股票名称专项对齐

用户指出 Codex PRO 应为旧版金色、股票名称字体仍不一致。本次仅修改 AI-bot，旧程序和实体设备不切换。

## 已确认原因与修正

- 现场缓存 Codex 套餐为小写 `pro`，原匹配只接受 `PRO`，因而使用默认灰白色。取数与渲染加入大小写、空白及 PRO LITE / MAX 别名归一化；固件接收端也兼容旧缓存/旧发送端。桌面使用旧版 RGB(255,159,10)，实体固件使用旧版 TFT_ORANGE，不擅自把两种旧平台调色板统一。
- 股票设备名称位图此前使用 GDI+、12 像素和纯白。旧实现实际为 TextRenderer、微软雅黑 UI 9 点常规、RGB(210,210,210)、右对齐/垂直居中/单行/无额外留白/省略号。已恢复相同渲染规格；桌面镜像仍保留自己的旧版 12 像素浅灰规格。
- 纳斯达克 `.IXIC` 曾被点号分割截成空串；改用市场前缀后的完整代码，现有缓存读取时同步纠正显示代码。指数价格恢复旧版分档：>=10000 无小数，>=1000 一位，其余两位。

## 证据

- `--audit-legacy-stock-labels` 只读取得旧运行程序 `/stock` 与 `/stock/names.raw`，先验证股票顺序，再将两种 RGB565 字节序统一后比较：6 只股票、62400 像素、差异 0。未把旧位图保存或加入仓库。
- 单/双额度测试逐像素验证 `pro` 与 `PRO` 完全一致，并断言存在旧版金色像素；别名、取数、镜像、策略、迁移回归通过。
- Windows Release 构建 0 警告/0 错误，固件构建通过，`git diff --check` 通过（Git 仍提示既存行尾转换）。
- 旧 AIClockBridge PID 55568、旧状态 HTTP 200。未刷写、未启动新版常驻、未发布。

股票结论只覆盖名称位图，不扩大成全部股票页或真机验收。PRO 固件颜色修正、动画形态、其他页面和 Wi-Fi 回退仍须后续验证。
