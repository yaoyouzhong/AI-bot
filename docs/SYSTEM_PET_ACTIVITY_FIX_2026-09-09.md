# 系统监控、桌宠和活动页现场修复

用户反馈：系统监控曲线/数字刷新有问题、活动页底部不全、桌宠刷新不对。旧版只读核对来源：`SystemStatsMonitor.Snapshot`（CPU/内存最多每秒）、`NetSpeedMonitor.CurrentSmoothed`（最近 4 样本平均）、固件 `netDrawTick`（250ms 消费队列）、数字变化检测及图表逐行合成。

## 本轮实现

- Windows 保留 250ms 原始网速采样，标题数值改为最近 4 样本平均；CPU/内存每秒更新。系统镜像 CPU/MEM 字体使用固定像素单位，避免桌面 DPI 再放大。
- 协议新增可选会话/序号/12 条原始尾部样本，设备按序去重并定时消费；旧无扩展发送端保留兼容路径。USB 心跳省略样本尾部以控制帧长，快速 metrics 帧负责补采；LAN 保留尾部。macOS 没有主动升级生产者，不将兼容性称为新节奏已实测。
- 系统静态框架只在进入或资源/在线代次变化时绘制；数字改变才绘制，使用小离屏缓冲完整替换，不先暴露空白；图表逐行合成后一次推送一行，不清整屏。
- 活动页底部 C/X 本机 Token 值分列，底边预留空间，重置次数上移，显式恢复左上对齐。新增最大 uint Token 图像样例和底边检查。
- 桌宠页不再由 100/180ms 外层时钟强制清屏；已导入 APET 自己的帧延迟负责播放，工作时更新帧，空闲保留帧；标题和底部仅内容变化时重画。Windows 镜像宠物纵坐标同步为 49。

## 验证

- Windows Release 0 warnings/errors；系统真实采样、镜像、DPI、页面布局测试通过。`activity-system-bounds.png` 已查看，最大 Token 值及 CPU/MEM 100%/9% 均完整。
- 固件 523856 bytes，COM7 写入 Hash verified。编译保留既有 TOUCH_CS/日期告警，另有不影响行为的缩进和两项已不再使用的桌宠局部状态告警；未把构建称为零告警。
- `--test-system-refresh` 第一次：5 秒内 20 帧/20 样本、静态框架 0 次、未变数字 0 次；第二次 21 帧/21 样本（包含计数请求边界时间），同样没有重复静态绘制。9%→100%→9% 恰好两次数字替换，未引入额外重画。
- 数字残影、曲线观感、活动页及宠物实体显示仍需用户看屏确认。只验证本轮，不代表全功能、Wi-Fi 或 Mac 验收通过。未恢复旧版、未推送发布。
