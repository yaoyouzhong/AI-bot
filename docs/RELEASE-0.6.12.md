# Windows 0.6.12 / TAB5 0.2.282-ui

本次发布改善 Windows 设备中心账号数据按钮的布局，并将 TAB5 预览窗口居中。TAB5 固件调整系统告警、诊断页和检测详情，避免告警图标与标签重叠。Mac 保持 0.6.11，ESP8266 保持 0.5.7，现有图库不变。

用户已确认 TAB5 .282 系统告警、诊断、检测详情和返回操作正常；Windows 新布局已通过界面检查。TAB5 首刷与升级包包含同一份已验收应用，升级时保留设备现有设置。电脑安装前正常退出旧程序，安装时保留设置与配对。

## English

Windows 0.6.12 tightens the account-data buttons and centers the TAB5 preview. TAB5 0.2.282-ui improves system alerts, diagnostics and details. The user confirmed the .282 screen and navigation on the device. First-install and upgrade packages contain the same accepted application. Mac remains at 0.6.11 and ESP8266 at 0.5.7; optional galleries are unchanged. Preserve device settings when upgrading.
