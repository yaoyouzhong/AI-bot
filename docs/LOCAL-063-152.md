# 2026-10-08 本地更新

Windows 桥接 0.6.3 与 TAB5 0.2.152-ui 已在本机／设备更新。此次只做本地交付，没有推送、标签或公开发布；公开下载索引保持原样。macOS 仅同步桥接版本元数据，未在 Windows 上构建或验收 macOS。

## 变化

- 网易云音乐只读补齐播放时间、中文别名、歌手和专辑，两个屏幕复用桥接采集结果。保留现有协议字段，ESP8266 无需为此刷机。
- TAB5 音乐页分组展示封面、曲名、别名、歌手和专辑，当前／总时间分列进度条两端，不加字段前缀；横向封面保留完整比例，未知时间不伪造进度。
- Codex「本周已使用」进度条分成七个等宽区段（一天计划用量为周额度的 1/7，约 14.3%）。分隔线不改变真实用量的连续填充，不代表每天实际已用量。
- 每 500 ms 更新音乐状态时仍持续发送 Wi-Fi／BLE 封面分片；Wi-Fi 已认证通信独立显示。保留 USB > Wi-Fi > BLE 优先级。
- 一并包含开机启动保存反馈、服务状态窗口、更新窗口、股票搜索／排序及天气设置独立保存，以及 TAB5 .151 的入口与天气明细调整。
- 后续本地界面补修：更新窗口的本地版本相同／更高时隐藏升级动作，移除重复名称／状态，表头改为「最新发布」。有更新的小屏仍保留升级条件和操作。第一轮补修包在 `artifacts/development/local-063-update-center-package/`。
- 更新窗口进一步按内容收紧高度，消除底部大块空白。「查看全部更新说明」提供电脑桥接、TAB5 和小屏三个组件标签页，区分当前运行版本、随包本地说明和已发布版本说明；标题、列表和下载资料直接排版，链接可点击，下载资料排在功能改动之后。随包说明离线可用；未连接设备不会冒称其已运行随包版本。新补修包在 `artifacts/development/local-063-update-notes-package/`，只更新本地桥接。
