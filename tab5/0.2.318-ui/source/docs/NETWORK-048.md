# 0.2.48：电脑状态曲线绘制与局部刷新

## 现场基线

2026-09-29 17:55:45 USB 诊断确认设备仍是 0.2.46，当前页面 4（电脑状态）。一次大面积刷新记录为 400237 us，最近绘制记录为 369938 us，历史大帧峰值 572220 us；显示欠载、刷新错误和超过 50 ms 的 LCD 帧间隔计数均为 0。看门狗累计计数为 3，不能据此证明本次闪屏由看门狗触发。用户观察到曲线卡顿、偶发闪屏，尚未定位闪屏的单一原因。

旧实现每个采样点分别更新 LVGL 数组并使控件失效，下载面积又拆为数百个三角形和矩形，部分刷新时重复产生大量绘图任务。动态电脑状态页同时进入整页缓存构建，频繁更新使缓存反复失效。

## 修改

- 保留桥接的 250 ms 原始样本、序列去重和缺失数据空档；图表明确标注“1 秒均值”，只对曲线使用最近四个连续有效样本的算术平均。顶部上传、下载数字仍是实时速率。
- 将线条、填充和网格预先合成为 774×250 的 RGB565 图像，使用约 378 KiB PSRAM。每次新样本仅合成一次，按行连续写入；LVGL 每个可见条带只需一个图像任务。工作数组为静态存储，避免占满 10 KiB UI 任务栈。
- 电脑状态页退出整页快照缓存，保留四个主页面的缓存策略。
- 采样播放改为固定时间轴，取消积压超过 16 点时每次推进三点的加速。初次历史留出四点（约一秒）缓冲；断流时冻结，收到真实样本后继续，不伪造流量。
- 50 ms 轻量定时器仅在像素位置变化时使图表失效，在两个真实样本之间逐像素横移。隐藏、触摸、OTA 时暂停该定时器的绘制。长时间暂停后恢复到已收到的真实历史，避免漫长追赶。
- 纵轴在增长时立即扩展，下降时缓慢收缩；左下角显示实际已有样本的时长，最多 56 秒。刚连接历史不足时保留空白，不把十几秒数据拉伸为一分钟。
- 累积包含 0.2.47 的两种字号货币符号修复：¥、￥、€、£、—、•。现场设备未安装 0.2.47，因此此问题须升级后复验。

## 验证与限制

原生真实 LVGL 检查：四种横移偏移下整帧与分块刷新逐像素一致；仅图表区域反复刷新无旧条带残留；每次整屏分块绘制曲线最多 5 个图像任务、0 个线段任务；检查上升/下降段连续性、动态页不重建缓存、1 GB/s 数值范围、均值、空档、乱序/重复序列、重连、积压和断流缓冲。采集本机 54.25 秒、217 个连续真实流量样本进行同样回放验证，未使用人为波形作为真机流畅度证据。RGB565 复制与绘制像素用例另外执行。

ESP32-P4 构建和镜像身份/校验另存候选 checks。预览和模拟测试不能证明 P4 绘制耗时、LCD 无闪屏或无线三通道真机通过。
