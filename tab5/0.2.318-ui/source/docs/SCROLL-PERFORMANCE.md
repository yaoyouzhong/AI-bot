## 0.2.18 结果及 0.2.19 页面缓存候选

- 0.2.18 真机选择原旋转路径（choice=1），分片比较 2457 / 2393 微秒，差异约 2.6%，未达到 10% 切换门槛。用户反馈仍卡顿、显示正常，因此旋转分块比较没有解决问题。
- 新候选先减少重复绘制：两个 RGB565 页面缓存槽，总上限 4 MiB，显式使用 PSRAM；空闲时每次只生成 64 行，300 ms 内有输入、正在按下/滚动、有动画或处于录音/拍照/升级时不预热。进入录音、相机、升级前释放缓存。
- 仅缓存指定的不透明、无变换容器。文字、样式、内部滚动变化立即失效；祖先的滚动只平移缓存。已有完整缓存只重绘变化区域，新缓存按整页生成。分片生成过程中如有变化，从新修订区域的第一行重新生成，完成前仍走原绘制。内存不足保留原路径。
- 真实按下反馈也纳入缓存检查：按钮去掉主题隐式延时动画，保留立即变色。按下后拖动时允许修复已有缓存的小区域，每次最多 81,920 像素，不在触摸期间分配或启动整页预热。原生触摸测试中应用按钮的按下画面用 2 次有限修复完成，拖动后的画面与原绘制一致。
- 缓存仍作为 LVGL 普通图片进入原绘制、旋转和显示路径，没有改 LCD 双缓冲所有权、刷新时序和相机直出。索引 29/30/31 分别记录命中次数、完成生成次数、缓存字节数，保留原诊断字段。
