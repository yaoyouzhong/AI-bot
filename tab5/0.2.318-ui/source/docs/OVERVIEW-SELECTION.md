# 总览默认会话（0.2.21）

0.2.22 增补：桌面可能在整轮执行期间缓冲 rollout 日志，实际日志文件时间会滞后。桥接后台通过既有桌面 IPC 只读查询会话拥有者，以新鲜的实时状态覆盖日志状态，不打开会话、不发消息。最近 8 项优先刷新，其余任务分批轮询，同时保留运行中的任务；查询失败时移除旧实时结果，回退日志来源。实时结果最多保留 60 秒。

总览显示「运行中」「等待操作」或「空闲 · 最近会话」，项目名标为「项目 · 名称」。设备名称 M5Stack TAB5 在顶部独立显示，通知出现时临时让位。

- 电脑桥接按会话自己的生命周期事件判断工作状态，优先正在工作的会话，多个工作会话按最近活动时间选取；没有工作中的会话时，取最近活动的会话。
- 状态来自现有后台扫描器，初次扫描最近活跃的根会话时从文件末尾向前寻找开始/结束事件，随后增量处理；子 Agent 不参与默认会话。没有明确开始事件不凭最近写文件认定工作中；Codex 进程已退出或工作会话 10 分钟无活动时不再报告工作中。
- 新增可选 `codexTasks.overviewTask`，包含 `id/title/folder/projectId/state`。总览不再直接使用可能因查看回复而被置顶的任务数组第一项；旧桥接回退按 `updatedAt` 选最近项。
- 总览自动更新不改变 Codex 编辑页已选会话及草稿。点击总览「继续 Codex 任务」才切换到卡片所示会话，并先保存现有草稿。
- 主链路需要新版桥接和 0.2.21 固件配合。主机单元测试、LVGL 模拟测试和实际设备验收分别记录。

## 0.2.25：未读完成优先

- 公共桥接从日志生命周期和桌面实时状态提取明确完成的轮次；空闲、中断不当成成功完成。完成提醒覆盖电脑直接发起的任务。
- 总览优先显示本机未读完成任务、未读数量与「查看完成内容」，读完后恢复正在工作/最近会话。自动刷新不改变当前编辑任务或草稿。
- 点击后保存草稿，切到对应项目和任务，并请求该已完成轮次的第 1 页；即使任务开始新一轮，也不会误打开新轮次。
- 点击、请求成功或普通心跳均不清除未读；匹配轮次的内容真正显示后才清除。首次连接保留静默基线，避免历史任务集中鸣响。
- 原生 LVGL 测试已覆盖完成优先、精确轮次请求、草稿保留、不发送消息及未读保留。桥接生命周期/协议测试通过；实际新完成事件的设备提示仍需独立观察。

## 0.2.26：公开文字与已读修正

- 兼容桌面日志 `AgentMessage` 的大写 `Text` 内容；只有解析出有效文字后才记录消息去重 ID，避免后续 `output_text` 副本被误过滤。
- 运行中轮次优先使用桌面 IPC 的公开文字，包含尚未完成写入日志的文字；历史轮次保留日志读取。两种来源的相邻分页保持一致。
- `replyView.hasText` 明确区分正文与占位提示。固定查看已完成轮次时，匹配轮次的有效正文显示后清除未读，不再要求“跟随最新”。空占位、其他轮次、读取失败不清除；空白的固定轮次仍重试读取。
- 真实会话“各种界面优化”的当前及两轮历史读取已通过桥接代码验证；原生界面验证固定轮次已读、空占位保留、轮次隔离和心跳不重复提醒。设备安装和用户操作结果另外记录。
