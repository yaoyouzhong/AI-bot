# 电量估算

0.2.35 修复插入 USB 后电量快速跳到 100%：旧实现直接以 (电压mV-6600)/16 换算百分比，充电导致的端电压抬升也会被当成剩余电量。

INA226 继续每 2 秒采集电压和电流；有基准后，按官方标准 2000 mAh 电池的测得电流积分更新估计值。充电电压不直接提高百分比；高电压且电流进入小电流区持续 10 分钟才校准到满电。放电开始后留出 60 秒稳定期，再以最多每分钟 1 个百分点向较低的电压估计修正。无效读数显示未知；采样中断超过 10 秒不累计缺失期间的电量。

充电中冷启动时没有可靠的静置电压基准，显示 `--`，充电闪电仍显示。拔掉外部电源并放电约 60 秒后建立电量基准；也可在持续满足满电估计条件后恢复数字。当前不保存跨重启电量历史，避免把更换电池或关机期间耗电当成已知值。

这是软件估算，不是专用电量计读数；电池老化、不同容量电池、负载和温度仍影响误差。修正范围是插拔电源时突跳及过早显示满电，没有修改充电芯片的控制逻辑或电压阈值。

模拟验证覆盖插电电压抬升、充电积分、小电流满电确认、拔电、冷启动充电未知、缺失采样及上下限；实际充放电曲线待安装后观察。
