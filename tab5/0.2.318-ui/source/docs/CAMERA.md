# TAB5 摄像头（本机预览开发版）

「Codex 任务」页的「打开摄像头」打开全屏预览；「拍摄」保留当时的画面供现场检查，「重拍」重新开始预览，「关闭」退出。拍摄画面只留在本次 TAB5 内存中，不保存到存储卡、不上传电脑，也不会自动发送给 Codex。下一阶段才连接任务附件，届时要在屏幕上明确显示发送对象并由用户确认发送。

设备端使用 M5Stack 官方示例的 ESP Video、SC202CS 传感器、SCCB 和 ISP 组件，调用 BSP 的 24 MHz 摄像头时钟和共享 I²C 总线。摄像头只在用户打开预览时初始化与取帧；预览使用 1280×720 RGB565，拍摄后停止取帧。摄像头未就绪时显示错误，其他状态页仍可继续使用。

来源与许可见根目录 `THIRD_PARTY_NOTICES.md`。当前只按官方示例的 SC202CS、1280×720 配置构建；实际设备摄像头型号、画面方向、帧率、散热、内存和打开关闭稳定性仍需真机确认。构建通过只说明源码能链接，不表示摄像头已采集到画面。

2026-09-24 验证：ESP-IDF 5.4.2 构建成功，UI 模拟器完成 Codex 页面及摄像头错误状态覆盖层截图；加入摄像头后的应用镜像为 2,752,656 字节，仍小于 5 MiB 的 OTA 槽。没有刷机或采集真实照片。
