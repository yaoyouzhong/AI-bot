## 已完成的主要链路

- 豆包接口语音返回 TAB5、手动发送、USB 与无线同一路径已由用户确认可用；随后用户确认透明接收窗及大疆麦克风兼顾电脑直接使用均正常。仍有前台输入焦点约束，豆包自身提示并未隐藏。
- 相机拍照、编码及图文发送已在后续阶段由用户确认；历史相机失败章节保留作背景，不再列为当前未实现。
- 桥接子窗口紧凑布局、按钮/备注调整已有全量布局检查；天气窗口取消、定位等真实问题已处理。
- OTA 双槽、完整性校验、启动确认及崩溃修复已有多轮成功记录；“速度最优”及“每个新版本已验收”仍是独立事项。

## 不混入本轮完成承诺

- 纯 BLE 豆包语音已在 0.2.37 候选及配套桥接实现并通过模拟链路；尚未部署，不能把 BLE 状态在线当作语音真机验收。
- 手机扫码传图按此前决定暂缓；不擅自恢复该需求。
- macOS TAB5 桥接及未购入的实体键盘需要对应环境/硬件，不作为当前 Windows 流畅度修复的前置条件。
- 没有推送、标签或公开发布授权；保留原 ESP8266 协议、配置与轮播设置。
