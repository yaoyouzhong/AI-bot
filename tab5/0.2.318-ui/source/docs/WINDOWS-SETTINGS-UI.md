# Windows 桥接设置窗口修正（2026-09-27）

公共桥接代码位于相邻 `AI-bot/windows-app/AIBotBridge`。本次处理天气窗口首次打开反馈与设置窗口适配，不修改用户现有凭据或系统 DPI。

| 原问题 | 处理 |
|---|---|
| 天气页固定行高、说明文字被截断 | 字段等宽、说明自动换行；内容区可滚动，底部操作独立固定 |
| 高 DPI 下文字放大、控件尺寸未同步 | 明确 96 DPI 基线，在完整构造后统一缩放 |
| 托盘菜单点击时直接 Show/Activate | 先关闭菜单，再在下一次 UI 消息处理显示窗口；恢复最小化窗口 |
| 设备控制亮度行超出、TAB5 连接输入宽度固定 | 内容按可视宽度排列，状态文字及操作行可换行 |
| 语音设置窄窗口、授权状态行可能截断 | 同步使用适配宽度和 DPI 设置，状态可换行 |
| 定位失败仍显示旧地区，原因不明显 | 显示定位权限/临时失败状态，保留上次天气；设置页提供获取当前位置入口 |

定位和连接操作开始时立即禁用相关输入及按钮，显示进行中状态，完成后恢复；关窗后异步返回不会再更新已释放控件。

- 语音设置仅做只读设备检查和窗口预览；不启动录音。国产模型授权页进行源码布局检查，不为验收主动登录或跳转厂商页面。

## 用户验收与取消按钮补修

- 用户确认一次点击即可打开，布局完整，“测试连接”显示秦淮；实际运行的 `/status` 也显示 `南京 秦淮 / qweather / stale=false / Windows 自动定位`，桥接重启后仍自动更新成功。
- 用户随后指出“取消”无响应。根因是天气页及通用设置以 `Show()` 打开，但按钮只设置 `DialogResult.Cancel`；该值本身不关闭普通窗口。补上显式 `Close()`，并让取消跳过输入校验；天气、通用设置、循环展示和关于窗口同步处理。
- `SETTINGS_CLOSE_OK`：4 种窗口 × 模态/非模态 × 取消按钮/Esc/关闭，共 24 项真实 WinForms 行为检查通过。取消按钮修正版已部署。
- 自动定位维持开启时每分钟检查电脑的 Windows 坐标；相对保存位置移动至少 1,000 米便更新坐标并刷新天气。未移动时天气刷新间隔 15 分钟。关闭定位权限或定位暂时不可用时保留上次天气并说明原因，不承诺跟随无电脑桥接的 TAB5 自身位置。
